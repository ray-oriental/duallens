# DualLens 界面设计规范（v1.0）

适用范围：桌面扩展的弹出页、设置页、页面内元素、侧边栏，以及手机用户脚本面板。
产品行为与默认值见 [PRODUCT.md](PRODUCT.md)；接口与数据契约见 [SPEC.md](SPEC.md)。译文的 6 种排版样式由内容脚本的排版模块实现，本文只规定默认样式的取值，以及它们在设置页中的呈现。

线框图只示意布局和文案位置，不代表像素；线框与文案表冲突时，以文案表为准。线框符号：`[文字]` 是按钮或选中的分段，`[ ]` / `[x]` 是关 / 开的开关，`(*)` / `( )` 是选中 / 未选中的单选，`*` 跟在名称后表示当前选中，`v` 是下拉箭头。

## 1. 设计原则

**安静。** 默认什么都不出现；出现时占的地方尽量小。界面以中性灰为主，只有一个强调色，且只表示三件事：可以点、已选中、键盘焦点。没有渐变、发光、脉冲和用来吸引注意力的动效。普通失败不用红色。

**可预期。** 同一件事总在同一个位置、用同一个词。开关就是开关，改了立即生效；按钮就是动作，点了才发生。每个开启后才出现的界面都自带关闭入口。除了快捷键，所有功能都有可见的控件，不设隐藏手势。

**一屏讲清楚。** 弹出页不滚动；设置页每一组打开就能看懂，不常用的收进「高级」。说明文字不超过两行，默认值就是推荐值，不用向导。

取舍规则：

1. 少一个控件，好过多一个选项。
2. 先替用户做出合理的决定并让它可见，不让用户在使用前先做选择。
3. 出了问题，先自己恢复（换引擎、重试），再告知，最后才请用户动手。
4. 任何一个会让文字离开设备的动作，都要让用户在动作之前或同时看到去向。

## 2. 设计令牌

### 2.1 颜色

中性灰为主，一个蓝色强调色。浅色与深色跟随系统（`prefers-color-scheme`），v1 不提供手动主题开关。

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--dl-bg` | `#f6f6f7` | `#131316` | 弹出页、设置页的底色 |
| `--dl-surface` | `#ffffff` | `#1b1b1f` | 卡片、输入框、页面内浮层的底 |
| `--dl-inset` | `#efeff1` | `#101013` | 内凹区域：分段控件轨道、键帽、代码块 |
| `--dl-raised` | `#ffffff` | `#2a2a31` | 浮起的选中项、菜单、下拉 |
| `--dl-border` | `#e3e3e8` | `#34343c` | 分隔线、卡片描边（装饰性，不承载信息） |
| `--dl-border-strong` | `#7f7f8b` | `#82828f` | 控件边界、关闭状态的开关、线性图标 |
| `--dl-text` | `#1c1c21` | `#ececf1` | 正文 |
| `--dl-text-2` | `#575762` | `#a9a9b5` | 次要文字、说明 |
| `--dl-text-3` | `#6b6b76` | `#9494a1` | 辅助信息、占位符 |
| `--dl-accent` | `#3556d6` | `#8fa5ff` | 主按钮底、开关打开、选中、链接、焦点环 |
| `--dl-accent-hover` | `#2a47b8` | `#a9baff` | 强调色的悬停态 |
| `--dl-accent-soft` | `#e8edff` | `#252c4a` | 当前导航项、选中卡片的底 |
| `--dl-on-accent` | `#ffffff` | `#0f1530` | 强调色底上的文字 |
| `--dl-ok` | `#17704f` | `#5fcfa3` | 连接正常、已保存 |
| `--dl-warn` | `#8a5a00` | `#e3b04b` | 暂时性问题（可重试） |
| `--dl-danger` | `#b3283f` | `#ff8b9c` | 只用于破坏性操作：清除密钥、恢复默认、删除 |
| `--dl-scrim` | `rgba(16,18,27,.48)` | `rgba(0,0,0,.60)` | 手机面板与对话框的遮罩 |

强调色只有这些用途：主按钮、开关打开、当前选中项（分段、单选、导航）、链接、键盘焦点环。其他地方一律用灰。品牌的蓝绿双圆标志只用在应用图标和商店图里，界面内的标志是单色（`currentColor`）。

已计算的对比度（WCAG 2.2；文字要求 4.5:1，控件边界与状态要求 3:1）：

| 组合 | 浅色 | 深色 |
| --- | --- | --- |
| `--dl-text` 在 `--dl-surface` 上 | 16.97 | 14.58 |
| `--dl-text-2` 在 `--dl-surface` 上 | 7.13 | 7.38 |
| `--dl-text-3` 在 `--dl-surface` 上 | 5.26 | 5.73 |
| `--dl-text-3` 在 `--dl-bg` 上（最低） | 4.87 | 6.19 |
| `--dl-accent` 文字在 `--dl-surface` 上 | 6.08 | 7.35 |
| `--dl-on-accent` 在 `--dl-accent` 上 | 6.08 | 7.69 |
| `--dl-border-strong` 在 `--dl-surface` 上 | 3.95 | 4.53 |
| `--dl-border-strong` 在 `--dl-inset` 上 | 3.44 | 3.97 |
| `--dl-ok` / `--dl-warn` / `--dl-danger` 在 `--dl-surface` 上 | 6.06 / 5.93 / 6.38 | 8.94 / 8.65 / 7.71 |

所有文字令牌在 `--dl-bg`、`--dl-surface`、`--dl-inset`、`--dl-raised` 上都不低于 4.5:1；`--dl-border-strong` 与 `--dl-accent` 在这四种底上都不低于 3:1。改动任何颜色后必须重新核对。

### 2.2 页面内译文的颜色

译文插在网页里，不使用固定颜色，一律从原文的 `currentColor` 推导，这样在任何网页主题上都协调。内容脚本在 `dl-t` 作用域内定义四个变量（与上面的界面令牌互不相干，只是名字相近）：

| 变量（`dl-t` 作用域） | 取值 | 用途 |
| --- | --- | --- |
| `--dl-fg` | 默认样式取原文色的 78%：`color-mix(in srgb, currentColor 78%, transparent)` | 默认「轻微弱化」的译文文字色 |
| `--dl-line` | 原文色的 48% | 虚线下划线、引用块左细线 |
| `--dl-soft` | 原文色的 7% | 重试标记的悬停底 |
| `--dl-hl` | 原文色的 9% | 「背景淡色」样式的底 |

默认样式「轻微弱化」：只把文字色降到原文色的 78%，字号不变（行内译文 0.92em），与原文的间距 0.3em，行高沿用原文。弱化之后若与背景的对比度低于 4.5:1，逐级向原文色回调直到达标（内容脚本已有按祖先背景调和对比度的逻辑，沿用）。标题的译文建议不加粗、字号取标题的 0.75 倍，避免双倍的标题压过正文，具体由排版模块评估。

另外 5 种样式的取值：无装饰（原文色，不弱化）；虚线下划线（1px 虚线，`--dl-line`）；背景淡色（`--dl-hl` 底）；学习（模糊 4px，指到、聚焦或触屏按住时清晰）；引用块（左侧 1px `--dl-line` 细线，缩进 0.6em）。

### 2.3 字体与字号

不加载任何网络字体，使用系统字体：

```css
--dl-font: system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei UI", "Noto Sans CJK SC", sans-serif;
--dl-font-mono: ui-monospace, "Cascadia Mono", "SFMono-Regular", Consolas, monospace;
```

字重只用 400 和 600（中文字体通常只有这两档，500 会被渲染成 400 或 600，难以预测）。

| 令牌 | 字号 / 行高 | 用途 |
| --- | --- | --- |
| `--dl-fs-xs` | 12px / 1.4 | 键帽、芯片、原文小字、隐私句（最小字号，只用于次要信息） |
| `--dl-fs-sm` | 13px / 1.45 | 弹出页行内容、状态行、辅助说明 |
| `--dl-fs-md` | 14px / 1.5 | 设置页正文、标签、按钮、输入框（基准） |
| `--dl-fs-lg` | 16px / 1.4 | 卡片标题、上手卡片标题、手机面板标题 |
| `--dl-fs-xl` | 20px / 1.3 | 设置页的分组标题 |
| `--dl-fs-card` | 15px / 1.6 | 划词卡片里的译文 |

触屏设备上，输入框字号不小于 16px（避免部分移动浏览器在输入框获得焦点时自动放大页面）。

### 2.4 间距、圆角、阴影、动效

| 类别 | 令牌与取值 |
| --- | --- |
| 间距（4px 基准） | `--dl-space-1` 4、`-2` 8、`-3` 12、`-4` 16、`-5` 24、`-6` 32、`-7` 48 |
| 圆角 | `--dl-r-xs` 4（键帽、芯片）、`--dl-r-sm` 8（按钮、输入框、分段）、`--dl-r-md` 12（卡片、菜单、提示条）、`--dl-r-lg` 16（手机面板、对话框）、`--dl-r-pill` 999（开关、状态点） |
| 阴影 | `--dl-shadow-1`：`0 1px 2px rgba(16,18,27,.08)`（选中的分段）；`--dl-shadow-2`：`0 4px 16px rgba(16,18,27,.12), 0 0 0 1px rgba(16,18,27,.05)`（页面内浮层）；`--dl-shadow-3`：`0 12px 32px rgba(16,18,27,.18), 0 0 0 1px rgba(16,18,27,.06)`（对话框、手机面板）。深色下 alpha 分别提高到 .4 / .5 / .6 |
| 动效时长 | `--dl-dur-1` 120ms（悬停、按下）、`--dl-dur-2` 180ms（展开、淡入淡出）、`--dl-dur-3` 240ms（手机面板滑入） |
| 缓动 | `--dl-ease: cubic-bezier(.2, 0, 0, 1)` |
| 焦点环 | `outline: 2px solid var(--dl-accent); outline-offset: 2px`，所有可聚焦元素统一 |

动效规则：只动 `opacity` 与 `transform`；不做弹跳、脉冲、闪烁、闪光骨架；转圈每秒不超过一圈；一律遵守 `prefers-reduced-motion`（见第 8 节）。

## 3. 通用组件

弹出页、设置页、侧边栏和手机面板共用下面这些组件，只在尺寸上区分桌面与触屏。

| 组件 | 规格 |
| --- | --- |
| **主按钮** | 底 `--dl-accent`、字 `--dl-on-accent`、半径 8；常规高 36，弹出页与手机面板的主操作用大号（40 / 48，字重 600）。悬停 `--dl-accent-hover`。一屏最多一个主按钮 |
| **次要按钮** | 底 `--dl-surface`、边 1px `--dl-border-strong`、字 `--dl-text`；悬停底 `--dl-inset`。「显示原文」「测试连接」「取消」用它 |
| **文字按钮** | 无边无底、字 `--dl-text-2`，悬停底 `--dl-inset`。页眉链接、「更改」「重试」「知道了」 |
| **危险按钮** | 次要按钮的外观，字与边用 `--dl-danger`；只用于清除密钥、恢复默认、删除，且需二次确认 |
| **开关** | 34 × 20 的胶囊。关：透明底、1.5px `--dl-border-strong` 边、灰色圆钮；开：`--dl-accent` 实底、白色圆钮。原生 `<input type="checkbox" role="switch">`，整行可点。状态变化 `--dl-dur-1` |

| **单选卡片** | 卡片内带单选点；选中时边框 `--dl-accent` 2px、底 `--dl-accent-soft`。用于上手卡片第 2 步、AI 服务预设、译文样式磁贴 |
| **选择框 / 输入框** | 高 36（触屏 44）、半径 8、1px `--dl-border-strong` 边、底 `--dl-surface`；下拉箭头用 CSS 绘制，不用图片。错误态：边变 `--dl-danger`，字段下方出现 12px 说明 |

| **行** | 左：标题（14px）+ 说明（12.5px、`--dl-text-2`）；右：控件。行与行之间 1px `--dl-border`，最小高 52（设置页）|

| **提示条** | 见 6.5。底 `--dl-surface`、半径 12、`--dl-shadow-2` |
| **键帽** | 底 `--dl-inset`、1px `--dl-border`、半径 4、12px、使用正文字体 |

## 4. 弹出页

### 4.1 尺寸与高度预算

- 宽 360px（固定，不使用 `vw`），高度随内容，**默认状态和本站规则展开时都不超过 600px**（Chrome 与 Edge 的弹出页最高 600px，超出会出现滚动条）。
- 底色 `--dl-bg`，四周外边距 10px，区块之间 8px，区块是白色卡片（`--dl-surface`，半径 12，内边距 10 12）。
- 高度预算（以样稿实测为准）：默认状态约 558px；本站选「总是」或「从不」并出现路径行时约 594px。余量只有 6px，所以隐私句必须一行（多一行就会超过 600px），增强功能的行高固定为 32px，不再增加区块。
- 自上而下的顺序固定，不随状态调换：页眉、翻译卡片、本站卡片、增强功能卡片。

## 5. 设置页

### 5.1 布局与交互模型

- 独立标签页。宽屏：左侧导航 208px，内容区最宽 720px，整体居中，两栏间距 32px。
- 窄屏（宽度小于 720px，包括手机面板）：导航变为顶部的横向分段，可水平滚动，当前项自动滚入视野；内容单列，控件满宽、44px 高。
- 一次只显示一个分组，分组之间不滚动衔接。地址栏哈希对应分组：`#common`、`#ai`、`#enhance`、`#sites`、`#glossary`、`#data`、`#about`，弹出页的「更改」据此直达。
- 每个分组由一个页面标题（20px / 600）和若干张卡片组成；卡片内是「行」（左标题与说明，右控件）。
- 导航当前项用 `--dl-accent-soft` 底与 `--dl-accent` 字，其余为 `--dl-text-2`。没有图标，没有计数角标。

**保存方式：**

- **即时项**（开关、分段、选择、单选、滑块）：改动后立即写入，卡片右上角淡出显示「已保存」（`--dl-ok`，1.6 秒，`role="status"`），不弹提示、不需要保存按钮。
- **表单项**（有校验或副作用的）：AI 服务配置、网站规则编辑、术语编辑、导入配置。它们在自己的卡片内有「保存」和「取消」；卡片内有未保存改动时，切换分组或关闭页面会提示。
- 取消现在的整页长表单与页底的粘性保存条。
- 错误显示在对应字段下方（`--dl-danger` 小字 + 图标），不使用 `alert()`。

要点：

- 顶部一句话：「配置后，翻译文字会发送给你选择的服务。密钥只保存在这台设备上，不会同步。」
- 每张预设卡片：名称 + 一行说明（「需要密钥」「有免费模型」「OpenAI 兼容接口」；本地模型写「Ollama、LM Studio」，并带一个「文字不出本机」标签）；选中卡片用单选卡片样式。
- 服务面板里固定有一句去向说明：「使用后，网页文字和页面标题会发送给 {服务名}。」本地模型：「文字只发送到你本机的服务，不会离开这台电脑。」
- 本地模型：先选 Ollama 或 LM Studio（预填 `http://127.0.0.1:11434/v1` 或 `http://127.0.0.1:1234/v1`）；Ollama 需要设置 `OLLAMA_ORIGINS` 才允许浏览器扩展访问，面板里给一行说明和一个「复制命令」按钮。不显示密钥框。
- 「测试连接」结果就在按钮旁：成功显示「连接正常，412 ms，示例译文：你好，世界。」（`--dl-ok` + 对勾）；失败显示一句人话和「详情」展开，不报红。
- 保存之后，翻译方式的「自动」就会带上 AI 精修，弹出页的引擎行同步更新；保存即视为用户已知晓该去向。

## 6. 页面内元素

所有页面内元素都放在 closed shadow root 里，网页的样式和脚本碰不到它们，它们也不影响网页。**这些元素只有在对应功能开启（或用户显式触发）后才会出现。** 页面内浮层跟随系统的深浅色，不跟随网页主题。

### 6.1 译文

译文的排版样式共 6 种，默认「轻微弱化」（`muted`），由排版模块实现，数值见 2.2。设置页的磁贴与预览要和实际渲染一致。译文元素应带 `lang` 属性（目标语言），让读屏软件用正确的发音朗读。

### 6.2 悬浮球（开启后才出现）

- **外观**：36px 圆盘（触屏 44px），底 `--dl-surface`、1px `--dl-border-strong` 边、`--dl-shadow-2`，中间是单色标志，颜色 `--dl-text-2`。没有渐变、没有彩色。空闲时不透明度 0.6，悬停、聚焦或打开菜单时为 1。
- **状态**：已翻译时右下角出现一个 8px 的 `--dl-accent` 小圆点（带 2px 底色描边）；翻译中小圆点换成细转圈（遵守减少动效）。不显示数字，不闪烁。
- **自动半隐藏**（设置项「靠边自动半隐藏」，默认开）：空闲 2.5 秒后向所在边缘缩进，只露出 24px，不透明度 0.45；指针靠近、键盘聚焦或触摸时 `--dl-dur-2` 内回到完整位置。无动效偏好时直接切换。
- **拖动**：按下并移动超过 5px 开始拖动；松手后吸附到最近的左 / 右边缘，纵向保持，距上下各留 8px（加安全区）；位置按网站分别记住。拖动不是唯一方式：菜单里有「移到左侧 / 移到右侧」。
- **点击**：翻译 / 显示原文。**菜单**：右键、触屏长按 500ms、聚焦后按 Shift+F10 或菜单键；悬停时球的内侧显示一个小「更多」按钮。
- 全屏视频时自动隐藏。球以外的区域不拦截点击和输入。

```text
+----------------------------+
| 显示原文           Alt+A   |
| 仅译文               [ ]   |
| 本站  [按需] 总是  从不    |
+----------------------------+
| 移到左侧                   |
| 关闭悬浮球                 |
| 设置                       |
+----------------------------+
```

菜单项：翻译此页 / 显示原文（带快捷键）；仅译文开关；本站分段（按需 / 总是 / 从不）；移到左侧或右侧；**关闭悬浮球**；设置。「关闭悬浮球」把 `floatBall.enabled` 设为关，并显示一条一次性小提示「悬浮球已关闭，可在弹出页重新打开」。

### 6.3 划词图标与翻译卡片（开启后才出现）

- **选区图标**：28px 圆盘（触屏 44px），样式同悬浮球但不半透明，出现在选区末端右下方 6px 处，`--dl-dur-1` 淡入。滚动、点击别处、Esc、选区消失时立即淡出。设置里选「直接显示翻译卡片」时不出现图标。
- **卡片**：宽 320（最小 240，最大视口宽减 16），半径 12，`--dl-shadow-2`；默认出现在选区下方，放不下则翻到上方；可以拖动页眉移动，不可调整大小。
- **结构**：页眉一行（语言对「英语 → 简体中文」，12px、`--dl-text-3`；右侧图标按钮：复制、朗读（浏览器支持时）、更多、关闭）；正文：译文 15px；其下是原文（12.5px、`--dl-text-2`，仅在双语显示方式下出现，用虚线与译文隔开）；页脚一行：引擎标签（12px、`--dl-text-3`，如「微软机器翻译」）；若结果来自机器翻译且已配置 AI 服务，右侧有文字按钮「AI 精修」。
- **更多菜单**：仅译文 / 双语；换服务重新翻译（选服务与模型，不再默认占一行）；**关闭划词翻译**。
- **加载**：译文位置显示三个小点，轻微淡入淡出（减少动效时静止）；超过 1 秒改为「正在翻译…」。
- **失败**：「暂时没有翻译出来。」+ 文字按钮「重试」+「详情」；不报红。
- 焦点不被夺走：卡片出现后焦点仍留在页面，卡片是 `role="dialog"` + `aria-label="翻译结果"`，译文区域 `aria-live="polite"`，Tab 可以进入，Esc 关闭并把焦点还给页面。

```text
+--------------------------------------------+
| 英语 -> 简体中文           复制 朗读 ... x |
|                                            |
| 公共图书馆从来不只是装满书的建筑。         |
|                                            |
| Public libraries have always been more     |
| than buildings full of books.              |
+--------------------------------------------+
| 微软机器翻译                       AI 精修 |
+--------------------------------------------+
```

### 6.4 悬停翻译（开启后才出现）

- 按住修饰键（默认 Shift）并指向某段文字时，在该段上叠一个浮层矩形：1px 虚线、`--dl-accent` 的 60% 透明度、半径 4、外扩 2px，表示「将翻译这一段」。浮层画在 shadow root 里，不修改网页元素的样式。松开修饰键即消失。
- 翻译结果沿用页面译文的默认样式，插在该段之后；再按一次修饰键收起。
- 触屏：长按 500ms，达到阈值时给同样的浮层矩形反馈；移动手指或滚动会取消。
- 没有提示文字、没有气泡。第一次使用也不弹说明——说明在设置页的细项里。

### 6.5 隐私提示条（一次性）

在用户从未确认过去向的情况下，**第一次把文字发送给某个去向**时，在页面右下角显示一条提示条。

- 位置：右下角，距边缘 16px；若与悬浮球重叠则移到左下角。宽 320，半径 12，`--dl-shadow-2`，底 `--dl-surface`，内边距 12 14。
- 内容两行以内：一句说明 +「更换服务」「继续」和关闭按钮。「更换服务」打开对应设置分组；「继续」记录确认并开始发送；关闭按钮标为「取消，不发送」。
- 行为：发送前阻塞确认；焦点落在「继续」按钮，只有明确确认后才发送文字并显示翻译进度。关闭、取消或按 Esc 均不记录确认、不发送，页面保持原样；`role="alertdialog"`；以 `--dl-dur-2` 淡入。同一去向只提示一次，去向变化（例如换成另一个 AI 服务）再提示一次。
- 在上手卡片第 2 步确认过，或在设置里主动添加服务，视为已确认，不再出现。

文案：

| 去向 | 文案 |
| --- | --- |
| 微软（备用谷歌） | 本次使用微软免费翻译，网页文字会发送给微软；失败时改用谷歌。 |
| 谷歌 | 本次使用谷歌免费翻译，网页文字会发送给谷歌。 |
| 云端 AI 服务 | 本次使用 {服务名}，网页文字和页面标题会发送给 {服务名}。 |
| 本地模型 | 本次使用本地模型，文字只发送到你本机的服务。 |
| 划词 / 悬停 / 输入框 | 把「网页文字」换成「选中的文字」「这段文字」「输入框里的文字」 |

```text
+----------------------------------------------+
| 本次使用微软免费翻译，网页文字会发送给微软； |
| 失败时改用谷歌。                             |
|                           更改    [ 知道了 ] |
+----------------------------------------------+
```

### 6.6 错误与重试

- **段落级失败**：该段原文后出现一个很小的「重试」标记：16px 重试图标 +「重试」二字（12px、原文色的 60%）。没有红色、没有边框、没有惊叹号；悬停时原文色的 80%。读屏文本：「翻译未完成，重试」。点击后重新请求这一段。
- **页面级失败**（所有引擎都不可用）：不在网页里弹窗，只在弹出页状态行说明（见 4.4）。
- **显式命令没有结果**（例如在不能翻译的页面按 Alt+A）：底部居中出现一条深色小提示「此页面不能翻译」，2.6 秒后消失；与其他提示同样是中性色，不用红色。
- 文案三段式：发生了什么 + 我们做了什么 + 你可以做什么，例如「暂时连不上微软翻译。已改用谷歌。」「密钥无效。请在设置里检查。」不显示错误码和英文堆栈，需要时点「详情」。

### 6.7 输入框翻译提示（开启后才出现）

连按三次空格或按 Alt+I 后，在输入框旁出现一个小胶囊（12px、`--dl-surface` 底、1px `--dl-border` 边、半径 pill）：

| 状态 | 胶囊内容 |
| --- | --- |
| 翻译中 | 转圈 + 正在翻译… |
| 完成 | 已翻译成英语（1.6 秒后消失） |
| 写回失败 | 没能写入输入框。 [复制译文] |

不夺取输入框的焦点；撤销依赖浏览器原生的撤销栈（Ctrl+Z），不另设撤销按钮。

## 7. 侧边栏与手机面板

两者与弹出页、设置页共用同一套令牌、组件和文案，不另做一套。

### 7.1 侧边栏（文本翻译，Alt+S）

- 宽度由浏览器决定（不小于 320px），单列。标题「文本翻译」（16px / 600），关闭用浏览器自带的按钮。
- 自上而下：语言对（从 [自动检测] ⇄ 到 [简体中文]）→ 文本域（至少 6 行，上限 20000 字符）→ 主按钮「翻译」→ 译文区（复制 / 朗读）→ 引擎行与隐私句（与弹出页同一组件）。
- 当已配置多个 AI 服务时，才在语言对下方出现「服务」选择；否则不显示服务与模型。
- 顶部两个标签：「文本」「字幕文件」（原侧边栏里的本地字幕文件翻译：导入 SRT / VTT，翻译，导出双语文件）。视频字幕的开关不放在这里，放在弹出页和设置页。

### 7.2 手机面板（Android Edge + Tampermonkey）

手机没有工具栏按钮，所以弹出页变成「底部面板」，设置变成全屏面板。

- **入口**：Tampermonkey 菜单里的「DualLens」（打开面板）、「DualLens：翻译此页 / 显示原文」、「DualLens：设置」。悬浮球默认关闭，用户可在面板里自己打开。
- **底部面板**：内容与弹出页完全相同（同样的区块顺序和文案），单列、满宽（最大 480）。顶部有 36 × 4 的拖动条（装饰）和 44 × 44 的关闭按钮；顶角半径 16；遮罩 `--dl-scrim`；最高 94dvh，内容超出时在面板内滚动；底部留出安全区。点遮罩或关闭按钮收起，不依赖手势。

- **键盘弹出时**（输入密钥、术语）：用 `visualViewport` 让焦点所在的输入框保持可见。
- **设置**：全屏；页眉「设置」+ 关闭；其下是可水平滚动的分组标签；内容单列。底部面板的页脚「文本翻译」「设置」分别进入全屏文本翻译和设置。

## 8. 无障碍

**对比度。** 文字不低于 4.5:1，控件边界、开关关闭态、焦点环不低于 3:1（已按 2.1 验证）。不只靠颜色传达状态：成功、注意、失败都配有文字，开关有位置变化，选中项有边与粗体。

**键盘。**

- 所有控件可用键盘到达，Tab 顺序与视觉顺序一致；焦点环统一（2.4）。
- 弹出页打开时焦点在主按钮，Enter 即可翻译；Esc 关闭（浏览器行为）。
- 开关用 `role="switch"`，空格切换；分段控件与单选卡片是单选组，方向键移动；设置页导航是 `<nav>` 里的链接，当前项 `aria-current="page"`；手机上的分组标签用 `role="tablist"`。
- 悬浮球、选区图标是真正的 `<button>`，有 `aria-label`；拖动有菜单里的替代操作。
- 页面内提示条与卡片不抢焦点，但都能被 Tab 到、被 Esc 关闭。

**读屏。** 状态行与「已保存」用 `aria-live="polite"`；只有阻断操作的错误才用 `role="alert"`。译文带目标语言的 `lang`。开关变化时播报「划词翻译，已开启」。「学习模式」的模糊译文仍在 DOM 中，可被读屏朗读。

**减少动效。** `prefers-reduced-motion: reduce` 时：所有过渡与淡入淡出取消，状态直接切换；转圈替换为静止的环或「…」；悬浮球的半隐藏不做滑动；设置页「已保存」直接出现、1.6 秒后直接消失。

**点击区域。** 桌面不小于 24 × 24（WCAG 2.2 AA），触屏不小于 44 × 44；开关整行可点。

**强制颜色模式。** `forced-colors: active` 时边框改用 `CanvasText`，开关用 `Highlight` 表示打开，焦点环用 `Highlight`；不依赖背景色区分状态。

**缩放与文字大小。** 弹出页与设置页在 200% 缩放和系统大字号下不横向滚动；设置页窄屏布局在 360px 宽度仍可用。

## 9. 中文文案规范

**语气。** 平静、直接、第二人称「你」，不用「您」。不用感叹号、不用 emoji、不用营销词（强大、智能、极致、一键、轻松、革命性、为你打造）。不解释显而易见的事，也不替功能说好话。

**句式。**

- 按钮和菜单项：动词开头，不带标点（翻译此页、显示原文、测试连接、清除缓存）。不在按钮里写「请」。
- 说明：短句，完整句子以句号结尾；单行说明不超过 14 个汉字（弹出页）或 30 个汉字（设置页）。
- 进行中用省略号「…」（正在翻译…）；省略号只用在进行中。
- 错误：发生了什么 + 我们做了什么 + 你可以做什么，三段不必都有，但顺序固定。不出现错误码。
- 中文与英文、数字之间留一个半角空格（AI 服务、Alt+A、46 段）；中文标点用全角，英文与数字旁用半角。
- 数字与单位：`412 ms`（毫秒可简写）、`3 MB`；区间用「到」，不用波浪线。

**术语表（界面内必须统一）：**

| --- | --- | --- | --- |

## 10. 实现提示

### 10.1 新增的设置字段（建议）

| 字段 | 类型与默认 | 存放 | 说明 |
| --- | --- | --- | --- |
| `floatBall.autoHide` | boolean，`true` | 同步区（与 `floatBall` 一起） | 靠边自动半隐藏 |
| `ui.onboarded` | boolean，`false` | 仅本机 | 上手卡片已完成或跳过 |
| `ui.acked` | string[]，空 | 仅本机 | 已确认过的去向标识，例如 `mt:microsoft`、`llm:{profileId}` |
| `ui.upgradeNoticeSeen` | boolean，`false` | 仅本机 | 升级后一次性提示已关闭 |

`ui.*` 是设备本地状态，不进同步区（每台设备各自确认去向）。这三项不参与导出，也不随「恢复默认」重置（避免再次出现上手卡片）。

### 10.2 与其他模块的约定

- 默认值、迁移（设置版本 3）、右键菜单精简：由对应的改动实现，本文假定它们按 [PRODUCT.md](PRODUCT.md) 第 2 节生效。
- 译文样式：由 15 种精简到 6 种（`muted`、`plain`、`dashed`、`highlight`、`blur`、`quote`），设置页的磁贴顺序与名称以此为准；旧配置里落在这 6 个之外的样式，迁移到最接近的一种。
- 设置页现有的长表单（`ui/forms/`）要拆成分组视图；`options.js`、`layout.js`、`index.js` 的职责边界保持：布局与字段生成、保存与导入导出、站点规则编辑分别在各自的模块里。
- `ui.css` 改为 `components.css` + 令牌；弹出页、设置页、侧边栏、用户脚本面板引用同一份。页面内元素把同样的令牌内联进各自的 shadow root。

### 10.3 验收清单

- 全新安装，打开任意网页，不触发翻译：页面里没有任何 DualLens 元素；工具栏图标没有角标。
- 弹出页默认状态高度不超过 600px；深浅色下对比度按 2.1 的表通过。
- 六个增强功能默认全部关闭；各自在弹出页打开后立即生效，关闭后立即卸载对应界面。
- 引擎行与隐私句与设置一致；切换引擎立即更新。
- 无设置时第一次发送前，页面出现阻塞确认卡；确认前零请求、零进度标记，关闭后页面保持原样；明确确认后同一去向不再出现。
- 手机 375px 宽度下，面板与设置页无横向滚动，所有控件不小于 44px。
- 开启「减少动效」后没有任何持续动画。

## 11. leader 拍板（2026-10-21，优先于上文）

1. **首次发送前确认（阻塞）**：用户若未在上手卡片或设置中确认过某个去向，第一次向该去向发送文字前，在页面角落显示确认卡（一句话说明发往哪里 +「继续翻译」「更换服务」），点「继续翻译」后才发送并记入 `ui.acked`；同一去向不再询问。本地模型（localhost）与「演示」不需要确认。
2. **手机端默认值与电脑一致**：悬浮球默认关；入口是 Tampermonkey 菜单（「翻译此页」「打开悬浮球」等），在 `docs/USAGE.md` 中说明。
3. **显式操作不受开关限制**：右键菜单、键盘快捷键（含 Alt+A、Alt+I）、侧边栏随时可用；开关只管「不请自来」的部分（选中即出现的图标、三次空格、Shift 悬停、悬浮球常驻）。
4. **界面语言**：v1 提供简体中文与英文两套界面文案（扩展用 `_locales` + `chrome.i18n`，界面语言跟随浏览器；用户脚本在体积允许时同样提供）。商店 listing 两种语言。
5. **按需权限**：默认不申请所有网站的读取/更改权限；工具栏、快捷键、右键菜单通过 `activeTab` + `scripting` 按需注入；需要常驻的能力（「总是翻译」站点规则、悬浮球、划词图标、悬停、输入框、跨域 iframe、漫画取图）在用户打开时用 `chrome.permissions.request` 申请可选主机权限，并在弹出页/设置中用一句话说明原因；用户拒绝时该功能保持关闭。翻译服务的固定主机写进 `host_permissions`；自定义接口与本地模型在保存时按来源申请。
6. **新增字段**：同意 10.1 的字段；目标语言默认跟随浏览器界面语言，匹配不上用简体中文。
7. **设置页即时保存**：按本文实现；若拆分长表单代价过大，可保留粘性保存条作为退路，其余设计不变。
8. **样稿不入库**：以本文为准。
9. **默认译文样式 `muted`**：文字色取原文色的 78%（向背景色混合），并保证对比度 ≥ 4.5:1；其余样式按 6 种 id 实现。
