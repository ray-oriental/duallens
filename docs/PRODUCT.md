# DualLens 产品说明

面向使用者、贡献者和商店审核者。界面规格见 [DESIGN.md](DESIGN.md)，接口契约见 [SPEC.md](SPEC.md)，数据去向的完整说明见 [PRIVACY.md](PRIVACY.md)，权限逐项用途见 [store/permissions.md](store/permissions.md)。

DualLens 是浏览器里的网页双语对照翻译工具。目标只有一个：**需要时好用，不需要时不存在。**

## 1. 产品哲学

四条原则并列。取舍冲突时，保护用户的一方优先于方便用户的一方。

### 克制

> 安装之后，页面上不出现任何 DualLens 元素，直到你主动触发。

- 触发只有三种：工具栏图标里的按钮、快捷键 Alt+A、右键菜单。
- 悬浮按钮、划词翻译、悬停翻译、输入框翻译、视频字幕、图片文字默认全部关闭。弹出页里有明确的开关，一次点击打开，也可以随时关回去。
- 不自动翻译任何网站，除非你给某个网站设置了「总是」。
- 不弹窗、不加角标、不打开欢迎页或更新说明页。不覆盖网页原有的样式，译文沿用页面自己的字体与颜色；显示原文之后，页面回到原样。
- 每一个开启后才出现的界面，自己带有「关闭此功能」的入口，不必回设置里找。

验收：全新安装后打开任意网页，不触发翻译，页面 DOM 中没有 DualLens 添加的任何节点，工具栏图标没有角标。

### 隐私

> 无账号、无遥测、无远程配置，开发者不接收任何数据。网页文字只发给你选择的翻译服务。

- 没有 DualLens 的服务器。扩展不向开发者或任何统计服务发送数据。
- 翻译时，待翻译的文字发给你选择的服务：默认是微软的免费机器翻译（失败时换谷歌）；如果你接入了自己的 AI 服务，文字和页面标题也会发给它。网址、cookie、表单内容不发送，密码框不处理。
- 第一次发送之前，用一句话说明发往哪里；之后弹出页常驻显示当前去向。
- API 密钥只保存在当前设备的本地存储里，不进同步区、不写日志；明文导出不含密钥，加密导出需要口令。
- 译文缓存只在本机，可以一键清除。使用本地模型时，文字只发到你自己的电脑。

验收：安装、打开设置页、打开弹出页，都不会向任何翻译服务发送内容。

### 免费

> 没有付费功能、会员、广告，也没有「免费版」和「专业版」之分。

- 默认引擎是免费机器翻译，不需要账号和密钥。
- AI 精修是可选项：用你自己的密钥或本地模型，费用由你与服务商结算，DualLens 不经手。
- 免费机器翻译是非官方接口，可能限流或变动，所以始终保留备用引擎，以及接入自有服务的路径。

### 开源

> MIT 许可。仓库里没有任何个人信息、个人服务或私有基础设施。

- 任何人克隆仓库后，都能构建、测试和使用，不依赖作者的机器或账号。
- 扩展包内不加载远程代码；第三方组件随包发布，许可证随附。
- 设计与决策写在文档里，欢迎在 Issue 里讨论。

## 2. 功能与默认状态

| 功能 | 默认 | 打开方式 | 关闭 / 撤销 |
| --- | --- | --- | --- |
| 网页翻译 | **手动**，不自动翻译任何网站 | 弹出页「翻译此页」；Alt+A；右键「翻译此页 / 显示原文」 | 「显示原文」 |
| 显示方式 | 双语对照 | 弹出页分段控件；Alt+W | 切回即可 |
| 悬浮按钮 | **关** | 弹出页开关 | 开关；悬浮按钮菜单「关闭悬浮按钮」 |
| 划词翻译（含选区小图标） | **关** | 弹出页开关 | 开关；翻译卡片「更多 → 关闭划词翻译」 |
| 悬停翻译 | **关** | 弹出页开关 | 开关 |
| 输入框翻译 | **关** | 弹出页开关 | 开关 |
| 视频字幕 | **关** | 弹出页开关；右键视频「视频双语字幕」 | 开关 |
| 图片文字（漫画与图片 OCR） | **关** | 弹出页开关；开启后右键图片出现「翻译图片文字」 | 开关 |
| PDF 阅读 | 不接管 PDF | 在 PDF 页面的弹出页点「用 DualLens 打开此 PDF」 | 关闭阅读页 |
| 文本翻译 | 手动 | 弹出页「文本翻译」；Alt+S（侧边栏） | 关闭侧边栏 |
| 站点规则 | 无 | 弹出页「本站」：按需 / 总是 / 从不，可限定当前路径 | 改回「按需」 |
| 翻译引擎 | 免费机器翻译（微软，失败换谷歌）；配置 AI 服务后自动变为「机器翻译秒出 + AI 精修」 | 设置 → 常用 / AI 服务 | 设置 |
| 译文缓存 | 开，仅本机 | 设置 → 数据与隐私 | 一键清除 |

补充规则：

- **显式操作不受开关限制。** 右键「翻译选中文字」、Alt+I「翻译当前输入框」、右键视频是用户当下的明确动作，始终可用；开关控制的是「不请自来」的那一部分（选中即出现的小图标、连按三次空格、按住 Shift 悬停等）。
- **右键菜单只有四项：** 翻译此页 / 显示原文；翻译选中文字；视频双语字幕；翻译图片文字（仅在图片文字开启后出现）。
- 快捷键默认：Alt+A 翻译 / 显示原文，Alt+W 双语 / 仅译文，Alt+I 翻译输入框，Alt+S 文本翻译。可在浏览器的扩展快捷键页修改。

## 3. 翻译方式

| 方式 | 行为 | 何时使用 |
| --- | --- | --- |
| 自动（默认） | 机器翻译先出结果；如果配置了 AI 服务，后台精修并原位替换；精修失败则保留机器翻译 | 绝大多数情况 |
| 只用机器翻译 | 不调用 AI 服务 | 求快，或不想把文字发给 AI 服务 |
| 只用 AI 服务 | 不使用免费机器翻译，文字只发给所选 AI 服务 | 隐私要求高，或使用本地模型 |

「AI 服务」支持：OpenAI、DeepSeek、OpenRouter（可发现免费模型）、本地模型（Ollama、LM Studio）、自定义的 OpenAI 兼容接口。

## 4. 关键用户旅程

### 4.1 第一次安装

1. 在商店点「添加」。浏览器会显示权限提示（读取和更改网站数据）。每项权限的用途写在商店页和 [permissions.md](store/permissions.md) 里。
2. 安装完成后**什么也不会发生**：不打开新标签页，图标没有角标，页面没有任何变化。
3. 点工具栏图标（新装的扩展默认收在拼图菜单里，可以固定）。**第一次**打开的弹出页显示一张三步上手卡片：
   1. 选择目标语言（默认跟随浏览器语言）；
   2. 选择翻译方式，并在同一屏看到文字会发往哪里；
   3. 完成，并告知「点翻译此页，或按 Alt+A」「其他功能默认关闭，随时在这里打开」。
4. 卡片可以「跳过」。跳过等于接受默认值（免费机器翻译，目标语言跟随浏览器）；因为没有确认过去向，第一次真正发送文字时，页面角落会出现一次性说明（见 4.6）。
5. 卡片只出现一次。之后每次打开，都是日常的弹出页。

### 4.2 翻译一个页面

1. 打开要读的网页，点图标，点「翻译此页」（或按 Alt+A）。
2. 视口附近的段落先翻译。译文紧跟在原文下方，沿用页面的字体，默认比原文略淡略小（「弱化」样式）；继续滚动，后面的段落再翻译。已配置 AI 服务时，译文在后台被精修并原位替换，页面不跳动。
3. 弹出页的状态行显示进度。个别段落失败时，只在该段旁边出现一个很小的「重试」标记，不弹窗、不报红。
4. 要看原文：点「显示原文」或再按 Alt+A。要只看译文：把显示方式切到「仅译文」。
5. 要让某个网站每次打开都自动翻译：在「本站」选「总是」；只想对某个路径生效，再打开「仅当前路径」。
6. 关掉弹出页之后，页面上除了译文，没有任何 DualLens 控件。

### 4.3 在弹出页打开某项更多功能

以「划词翻译」为例，其余五项相同：

1. 点图标，在「更多功能」里打开「划词翻译」。当前页立即生效，不需要刷新。
2. 在页面里选中文字，选区旁出现一个小图标；点它，出现翻译卡片。
3. 想关掉：回到弹出页关闭同一个开关，或在卡片的「更多」里选「关闭划词翻译」。
4. 不打开开关也能用：选中文字，右键「翻译选中文字」。

每项功能的细项（悬停修饰键、输入框写回方式、字幕字号、悬浮按钮靠边半隐藏等）在设置页「更多功能」里，弹出页只放开关。

### 4.4 接入自己的 AI 服务或本地模型

1. 设置 → AI 服务。顶部一句话说明：配置后文字会发给你选择的服务，密钥只存在这台设备上。
2. 在「添加服务」里选一张卡片：OpenAI、DeepSeek、OpenRouter、本地模型、自定义。
3. 云端服务：粘贴自己的密钥（卡片上有「获取密钥」链接），点「获取模型」，选一个模型。OpenRouter 可以只列出免费模型，并建议几个不同厂商的备选。
4. 本地模型：选 Ollama 或 LM Studio，地址已预填；Ollama 需要先设置 `OLLAMA_ORIGINS` 允许浏览器扩展访问，页面上有说明和可复制的命令。不需要密钥。
5. 点「测试连接」，看到一句示例译文和耗时后点「保存」。
6. 保存后，翻译方式自动成为「机器翻译秒出 + AI 精修」；弹出页的引擎行和隐私句随之更新。要停用，在 AI 服务页把「当前使用」改为「不使用 AI 服务」。

### 4.5 手机安装与从电脑迁移配置

手机浏览器没有工具栏按钮，所以手机版是 Tampermonkey 用户脚本（Android 版 Edge）。

1. **安装：** 在 Edge 的扩展目录安装并启用 Tampermonkey；打开 Release 里的 `duallens.user.js` 并确认安装。安装后页面没有任何变化。
2. **使用：** 打开网页，点 Tampermonkey 图标，选「DualLens」。屏幕底部升起一张面板，内容与电脑上的弹出页相同：翻译此页、显示方式、本站、更多功能、设置。
3. **要一键翻译：** 在面板的「更多功能」里打开「悬浮按钮」（默认关闭）。
4. **迁移配置：** 电脑上 设置 → 数据与隐私 → 「迁移到另一台设备」，设置口令，屏幕出现二维码和一段加密文本。手机用相机或扫码工具读出文本；在手机的 DualLens 面板 → 设置 → 数据与隐私 → 「从电脑导入」，粘贴文本并输入口令。口令请用另一个渠道告知自己，不要和二维码放在一起。
5. 配置包含 API 密钥，因此必须加密；不设口令只能导出不含密钥的明文。两台电脑之间，非机密设置可以走浏览器自带的同步，密钥仍需用同样的方式迁移。

### 4.6 什么时候、怎样告知数据会发往哪里

| 时机 | 方式 | 内容 |
| --- | --- | --- |
| 第一次打开弹出页 | 上手卡片第 2 步 | 选择引擎，并写明文字发给谁、失败时发给谁 |
| 之后每次打开弹出页 | 引擎行下面常驻一句话 | 当前去向，如「网页文字会发送给微软，失败时改用谷歌。」 |
| 第一次发送文字，且从未确认过 | 页面右下角一次性提示条，可关闭、不抢焦点 | 「本次使用微软免费翻译，网页文字会发送给微软；失败时改用谷歌。」 |
| 在设置里添加或切换 AI 服务 | 服务面板内一句话 | 「使用后，网页文字和页面标题会发送给 {服务名}。」 |
| 使用本地模型 | 同上 | 「文字只发送到你本机的服务，不会离开这台电脑。」 |
| 第一次使用图片文字 | 确认卡片，确认后才下载 | 需要下载本地识别语言包（体积、来源、可在设置中删除）；图片只在本机识别，只有识别出的文字发给翻译服务 |
| 任何时候 | 设置 → 数据与隐私 | 完整的「发什么、发给谁、存在哪」表 |

确认以「去向」为单位记录：同一个去向只说明一次；去向变了（例如换成另一个 AI 服务）会再说明一次。在设置里主动添加服务，视为已经知晓。

## 5. 不做什么

- **没有账号。** 不登录、不注册，不需要邮箱。
- **没有遥测。** 不统计使用、不上报崩溃、不嵌入第三方分析或广告 SDK。
- **没有远程配置。** 不从服务器下发开关、规则、文案或代码，不做 A/B 实验。
- **不自动打开页面。** 安装、更新后都不弹出欢迎页或更新说明；升级提示只出现在你主动打开的弹出页里，且只出现一次。
- **不做角标。** 工具栏图标不加数字、小红点或动画。
- **不推销。** 没有升级提示、捐赠弹窗、评分请求、「推荐给朋友」。
- **不自动翻译。** 除非你对某个网站选了「总是」，或在高级里指定了要自动翻译的页面语言。
- **不改网页。** 不覆盖网页样式，不在页面里注入常驻按钮，除非你打开了悬浮按钮。
- **不读与翻译无关的内容。** 不读取 cookie、账号信息和表单里的密码。
- **不自建云同步。** 设置同步依赖浏览器自带的同步；密钥永远不进同步区。

## 6. 平台差异

| | 桌面（Chrome / Edge 扩展） | 手机（Android Edge + Tampermonkey） |
| --- | --- | --- |
| 入口 | 工具栏图标 → 弹出页；Alt+A；右键菜单 | Tampermonkey 菜单 → 底部面板；悬浮按钮（需手动打开） |
| 弹出页 / 面板 | 宽 360 的弹出页 | 与弹出页同一套组件，单列，触控尺寸 |
| 设置 | 独立设置页，左侧导航 | 全屏面板，顶部分段导航 |
| 同步 | 非机密设置走浏览器同步；密钥只在本机 | 不自动同步，用加密配置迁移 |
| 不支持 | | Android 版 Chrome（无法安装扩展或用户脚本） |

## 7. 给商店审核者

- **权限：** 每项权限的用途与最小化理由见 [store/permissions.md](store/permissions.md)。
- **数据流：** 见 [PRIVACY.md](PRIVACY.md) 和本文 4.6。扩展不运营服务器；外部请求只发生在你触发的操作里：发往你选择的翻译服务，以及你明确要求的 PDF、图片和 OCR 语言包下载。
- **默认状态：** 见本文第 2 节。全新安装后没有任何页面注入的可见界面，所有更多功能默认关闭。
- **远程代码：** 扩展包内不加载远程脚本；OCR 与 PDF 组件随包发布。
- **可复现：** 源码为原生 ES 模块，无需构建；`npm test` 运行离线测试。
