# DualLens v1.1.0 — PDF 导出与扫描件识别，更清楚的报错

## 新内容
- **PDF**：阅读器可以导出双语 PDF：双栏对照或仅译文，可选页码范围，进度可见、随时取消。扫描版页面可开启本机文字识别后再翻译，图像不离开设备。阅读器换成与弹出页、设置页一致的单色设计。
- **报错**：每条报错都说清楚发生了什么、你可以做什么，并附「重试」「打开设置」「详情」。网络抖动、超时、限流会安静地自动重试；只有部分段落失败时，会显示数量，可一键重试这些段落。
- **体验统一**：所有界面使用同一套术语；按钮点下后统一显示进行中状态和带时间的结果；弹出页显示你实际设置的快捷键；侧栏文本翻译支持清空、交换语言和 Esc 取消；网站规则可以改名和删除；术语表导入会先校验；输入框模式的浮层可以按 Esc 关闭。
- **Android 用户脚本**：启动包从 345 KB 降到约 320 KB。视频字幕、图片文字和漫画识别改为按需加载，放在新增的 `duallens-features.js` 里，同样固定哈希校验后才执行。

## 安全与隐私
- 页面内的输入框、划词、悬停翻译和原位重试只响应真实的用户输入，网页脚本伪造的事件不会触发翻译。
- 翻译请求不再跟随重定向；所有响应限制在 4 MiB 以内。
- PDF 的临时交接数据过期后会被清理，不再长期留在浏览器里。
- 仓库启用了 Dependabot，自动检查固定版本的 GitHub Actions。

## 升级
- 扩展：在扩展管理页点「重新加载」，或等待商店自动更新。
- 用户脚本：重新安装 `duallens.user.js`；Tampermonkey 会自动获取同版本的 `duallens-settings.js` 和 `duallens-features.js`。

## 下载
- Microsoft Edge 加载项商店（审核通过后）。
- 开发者模式：`duallens-extension-v1.1.0.zip`；Android 用户脚本：`duallens.user.js`。校验值见 `SHA256SUMS`。
