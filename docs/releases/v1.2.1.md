# DualLens v1.2.1 — 本地 PDF：初始设置里可选开启，没开也能打开

## 新内容
- **初始设置可以选择是否开启文件访问**：扩展版的初始设置在「翻译方式」之后多了一步「本地 PDF」。这一步说明开关的用途：开启后，在浏览器里打开电脑上的 PDF，点 DualLens 就能一键打开；只读取你点的那一个文件，不会上传。
  - 默认是「暂不开启」。
  - 选「开启」会打开扩展详情页，请在那里打开「允许访问文件网址」（Edge 里叫「允许访问文件 URL」）。
  - 再打开 DualLens 时，会接着完成初始设置，并显示当前状态。
  - 已经开启的安装会跳过这一步。
  - 设置页「数据与隐私」里也能随时查看状态，并打开扩展详情页。

## 改进
- **PDF 阅读器的面板不再撑高工具栏**：「导出 PDF」和「识别文字（本机 OCR）」改为在按钮下方弹出的浮层，盖在页面上，不再把页面往下推。
  - 按 Esc、再点按钮或点页面就能收起；导出或识别进行中会保持打开，方便看进度。
  - 识别完成后自动收起。

## 修复
- **本地 PDF 打不开**：从 Edge 加载项商店安装的 DualLens，默认没有「允许访问文件网址」。用浏览器打开本地 PDF 后，弹出页认不出这是 PDF，也就不显示「用 DualLens 打开」。现在改为：
  - 弹出页的受限提示下面有「打开本地 PDF」，点它进入 DualLens 阅读器。
  - 阅读器会说明原因并显示文件名。点「选择本地 PDF」，选同一个文件即可打开；文件只在本机处理。
  - 「打开扩展详情页」直达这个开关所在的页面。开启「允许访问文件网址」后，以后可以一键打开。
  - 右键菜单「用 DualLens 打开此 PDF」也走同一条路径。

浏览器不允许扩展自己开启这个权限，只能由你在扩展详情页打开。开发者模式安装默认已开启，不受这个问题影响。

## 升级
- 扩展：商店版审核通过后会自动更新；开发者模式在扩展管理页点「重新加载」。
- 用户脚本：功能没有变化。Tampermonkey 会照常自动更新到 1.2.1。
