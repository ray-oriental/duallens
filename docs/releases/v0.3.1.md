# DualLens v0.3.1 — 流式翻译与 Pixiv / PDF 阅读修复

继续使用自己配置的模型服务，本机网关是可选增强。扩展保持零构建，用户脚本启动产物小于 400000 字节。

- 扩展 fetch、用户脚本 GM progress 与网关支持 OpenAI SSE；完整单项提前显示，首屏小批次；不支持时回退非流式。
- 404 模型立即回退并冷却；Hermes 目录取 proxy 与免费 allowlist 交集，实际 404 后隐藏。目录不保证即时可用性。
- Pixiv 小说按阅读段落切分，漫画旁列进入文档流，PDF 公式用占位符保护。
- Pixiv CDN 防盗链兼容：新增 `declarativeNetRequestWithHostAccess`，仅匹配本扩展 ID 发起的 XHR/other 取图请求，不影响网页请求、不扩大 host 权限。关闭漫画/移除名单删除规则，用户脚本带匿名 GM Referer。
- 悬浮球统一分派翻译/恢复，漫画面板也能恢复。
- PDF 等 JSON 批次中的单个人名漏翻不再丢弃其他正确译文；整批校验通过的成功项可先确认，漏翻项保留回退/失败提示。
- 编号加点引导线的 PDF 目录逐行切段，避免模型自行拆项造成数组长度错误；内容漏翻仅在当前任务换模型，不让整个可用模型进入网络故障冷却。
- JSON 数组长度仍错误时可从半批降为单项，每个初始批次最多八个追加请求，严格校验对应关系；不会把错位译文插入页面。
- 自动检测的源语言传给模型，编辑后更新；日文正文原样及明显近似回显按漏翻处理，流式显示前检查。漏翻项可缩批恢复，与 JSON 错项共用有限重试预算；缓存版本升至 4。
- 小说共用高 `<p>` 时按源节点范围分别判断可见性，远处段落滚动后才进入队列。实页读取探针有限重试导航异常，使用系统网络直连。
- 日译中首屏先发两段，其余批次保持用户配置容量，减少首段等待；不会默认调用付费订阅模型。
- 模式切换、译文插入后重新判断可见范围；SJTU 无输出进展时最多等待 12 秒再走备用链，持续输出仍可完成长回复。

下载资产为 duallens-extension-v0.3.1.zip、duallens-portable-v0.3.1.zip、duallens.user.js 与 SHA256SUMS；商店目标另生成 duallens-edge-store-v0.3.1.zip。发布与商店提交由 leader/用户负责。

离线 Chromium/GM 桩不能替代两台 Windows Chrome/Edge、Android 手机/平板真机验收。Android Chrome 书签版、EPUB、视觉模型与 iframe 翻译仍未实现。真实页面结果以本轮报告为准，复杂 OCR、SFX、混合方向与 PDF 跨栏仍有限制。详见 [漫画](../COMICS.md)、[PDF](../PDF.md) 和 [平台契约](../PLATFORMS.md)。

2026-10-14 授权探测中，Hermes ling-3.1-flash 与 longcat-2.0:free 返回 404，solar-mini4:free 返回中文成功。因此默认 allowlist 与一键接入仅自动选入 Solar，仍须出现在实时目录中；其它模型可由用户显式配置并手选，不更改现有设备配置。
