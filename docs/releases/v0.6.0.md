# DualLens v0.6.0 — 通用视频字幕、输入框双语、交互可单独选服务

## 视频字幕
- 不再只限 YouTube：页面里带标准字幕轨（`<track>` / `video.textTracks`）的 `<video>`（如 Coursera、TED、edX 和许多课程站）可以显示双语字幕，按播放位置调度翻译，拖动进度后重新排队，全屏时也可见；恢复后原生字幕的开关状态不变。没有字幕轨的视频不做处理（不做语音识别）。
- 侧边栏字幕页签可以导入本地 `.srt` / `.vtt`（≤ 2 MB），翻译后预览并导出双语 `.srt` / `.vtt`，全部在本地完成。
- 入口统一为「启用 / 恢复视频双语字幕」：任意网站在视频上右键即可；YouTube 仍为页面右键菜单。

## 输入框、划词、悬停
- 输入框翻译可选「替换」或「双语」（保留原句），可设原文/译文先后；多行输入用换行分隔，单行输入用空格分隔；只翻选区时不改动选区外文字。
- 写回更可靠：依次尝试多种写入方式并读回确认（受控输入、contenteditable、拦截输入事件的富文本编辑器）；输入法组合期间不触发；用户在等待时继续输入或结果迟到时不覆盖；全部失败时提示并可复制译文。
- 划词卡片可以临时选择服务与模型；悬停与输入框可以在设置里选择「继承网页翻译」或单独指定服务/模型，不影响网页翻译链。

## 其他
- 手机用户脚本启动包约 333 KB（设置面板仍按需加载，构建硬上限 360 KB）。

## 已知限制
- 字幕只处理顶层文档里的标准视频；私有播放器（如 Netflix）、关闭的 Shadow DOM 与 iframe 内的视频字幕暂不支持；被禁用的字幕轨需先在播放器里打开；不绕过 CORS。
- 复杂编辑器的撤销栈与延迟回滚不做通用保证。真实网站与真机待用户验证；本版验证为离线单测与 mock 浏览器测试（单测 428、扩展 E2E 33、媒体 11、输入 31、用户脚本 11、iframe 4、版式 12、PDF 6、设置页 8）。
