# DualLens v1.0.0 — 安静、私密、免费的双语网页翻译

DualLens 是一个开源（MIT）的浏览器扩展：在原文下方显示译文，保持网页原有排版。v1.0 是第一个面向所有人的正式版，围绕四条原则重做：

- **克制**：安装后网页上不会出现任何 DualLens 元素，直到你点工具栏按钮、按 Alt+A 或用右键菜单。悬浮按钮、划词翻译、悬停翻译、输入框翻译、视频双语字幕、图片文字翻译全部默认关闭，在弹出页「更多功能」里打开。
- **隐私**：无账号、无遥测、没有开发者服务器。网页文字只发给你选择的翻译服务（默认是微软免费翻译，失败时谷歌）；第一次发往某个服务前会先问你。权限按需申请：默认只在你点击时访问当前标签页。
- **免费**：默认使用免费机器翻译；也可以接入你自己的 AI 服务（OpenAI、DeepSeek、OpenRouter 等）或本地模型（Ollama、LM Studio），配置后先显示机器翻译、再由 AI 原位精修。
- **开源**：MIT 许可，代码、构建与测试全部公开。

## 新内容
- 重新设计的界面：安静的单色风格，弹出页、三步上手与七个分组的设置页（改动即时保存）；浅色与深色；简体中文与英文。
- 更安静的译文排版：沿用网页的字体、字号、行高与缩进；六种译文样式（默认轻微弱化、无装饰、虚线下划线、背景淡色、学习模式、引用块）。
- 首次发送确认：每台设备对每个翻译服务确认一次；本地模型无需确认。
- 按需权限：工具栏、快捷键与右键菜单通过 activeTab 工作；只有打开需要常驻网页的功能或设置「总是翻译」时才请求更大的权限，并说明原因。
- PDF：从当前标签页用 DualLens 打开 PDF，版式保持的双栏对照。
- iframe 与 Shadow DOM 中的文字、标准 HTML5 视频字幕、本地 SRT/VTT 字幕文件、输入框双语模式。
- Android：Edge + Tampermonkey 用户脚本，启动更轻（设置与面板按需加载）。
- 自定义 AI 服务更好配：基础地址只填了域名、拿到的是网页时，自动补成 `/v1` 再试；网页、无法解析、密钥无效、找不到接口分别给出明确提示；设置页每个按钮点下后都显示「正在…」，结果带时间，连点同样的错误也能看出是新结果。

## 从 0.x 升级
- 设置自动迁移。为了符合「默认安静」，悬浮按钮、划词、悬停、输入框与图片文字会在升级时关闭一次；打开弹出页即可重新开启。
- 原来的「本机网关」配置会作为普通的「自定义 OpenAI 兼容接口」保留，继续可用。

## 下载

- 开发者模式：`duallens-extension-v1.0.0.zip`；Android 用户脚本：`duallens.user.js`（需同版本的 `duallens-settings.js` 资源，由 Tampermonkey 自动获取）。校验值见 `SHA256SUMS`。
