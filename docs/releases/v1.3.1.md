# DualLens v1.3.1 — 浏览器里打开的 PDF 能可靠切换到 DualLens

## 修复
- **用 DualLens 打开浏览器里的 PDF**：在 Edge/Chrome 自带的 PDF 查看器里点「用 DualLens 打开此 PDF」，现在会在这个标签页里重新读取 PDF，沿用该页的登录状态和浏览器缓存。需要登录才能看的 PDF、地址不以 .pdf 结尾的 PDF、经过跳转的 PDF 都能打开，以前这些情况常常失败。
  - 打开后原标签页直接切换为 DualLens 阅读器，点「后退」可回到浏览器自带的查看器。
  - 读取失败时，会新开一个标签页说明原因，并提供本地文件选择；原来的 PDF 标签页保留不动。
  - 在 InPrivate/无痕窗口里，阅读器会单独打开，不保存阅读会话、不缓存译文；刷新后需要重新打开。
- **PDF 上按 Alt+A**：在浏览器自带查看器里按 Alt+A（Chrome 里也可以用右键「翻译此页 / 显示原文」），会切换到阅读器并开始翻译；以前按了没有反应。浏览器隐藏地址的标签页不受影响。
- **刷新阅读器不再丢文档**：刷新、后退再前进时保留当前 PDF。本机最多保存 3 个阅读会话，每个最大 64 MiB，保留 24 小时，关闭标签页即删除。
- **弹出页**：在 PDF 上只显示一个「用 DualLens 打开此 PDF」，不再报「受限页面」，也不再发网络探测请求。
- **老式表格论坛的版面**（[#33](https://github.com/ray-oriental/duallens/issues/33)）：在 phpBB 一类论坛上翻译后，「Page 1 of 23」「[ 337 posts ]」这类分页单元格不再被挤成逐字竖排，译文保持单行；面包屑导航（Board index » …）的译文跟在原文后面，不再每级一行。

没有新增权限。

## 升级
- 扩展：商店版审核通过后会自动更新；开发者模式在扩展管理页点「重新加载」。
- 用户脚本：Tampermonkey 会照常自动更新到 1.3.1，带上论坛版面的修复（PDF 相关改动只在扩展里）。

## 下载
- Microsoft Edge 加载项商店（审核通过后）。
- 开发者模式：`duallens-extension-v1.3.1.zip`；用户脚本：`duallens.user.js`。校验值见 `SHA256SUMS`。
