# DualLens v0.2.0 — 通用多平台版

任何人填入自己的模型服务即可使用；电脑（Chrome / Edge 扩展）与 Android 手机、平板（Edge + Tampermonkey 用户脚本）都能运行。

## 下载

- duallens-extension-v0.2.0.zip：浏览器扩展包，解压后在 chrome://extensions 或 edge://extensions 开启开发者模式并加载。
- duallens-edge-store-v0.2.0.zip：提交 Edge Add-ons 用的商店包（manifest 不含 key）。
- duallens.user.js：Tampermonkey 用户脚本（Android Edge：菜单 → 扩展 → Tampermonkey，再打开本文件链接安装）。
- duallens-portable-v0.2.0.zip：扩展、可选本机网关、文档、测试与脚本。
- SHA256SUMS：以上文件的 SHA-256。

## 新内容

- 设置 v2：可同步的公共设置与只存本机的密钥分离；服务商预设（OpenRouter 免费模型、DeepSeek、硅基流动、智谱、月之暗面、OpenAI、Gemini、Groq、交大、Ollama、本机网关、自定义）；跨服务的备选链；口令加密的配置导出导入。
- 用户脚本版与触屏交互：长按段落翻译、选区下方划词图标、可拖动悬浮球；用户脚本里的 key 只经隔离沙箱的原生对话框输入。
- 漫画翻译（第一阶段）：本机 Tesseract OCR，原图旁按阅读顺序列出原文与译文；图片不离开设备，只有识别出的文字发给你选择的翻译服务。默认只在 pixiv 启用 canvas 切片还原，可在设置里增删站点。
- Edge 商店上架材料与隐私政策。

## 已知限制

YouTube 字幕、PDF、Android Chrome 书签版与漫画视觉模型尚未实现；见 ROADMAP。
