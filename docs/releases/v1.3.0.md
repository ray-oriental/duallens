# DualLens v1.3.0 — 译文颜色可以自己选

## 新内容
- **译文颜色**：设置 → 常用 → 译文样式里新增「译文颜色」，让译文和原文更容易区分。
  - 默认「自动」，和以前一样按网页配色弱化原文颜色。
  - 可选蓝、紫、橙、绿、灰五种预设，也可以用取色器自定义。
  - 每种预设有浅色、深色网页两档，在深色网站上自动换成更亮的一档。
  - 颜色在网页背景上太淡时，会保持色相、自动调到看得清。
  - 对所有译文样式都生效，包括「无装饰」。改完后，已翻译的页面立即变色，不用重新翻译。
  - 浏览器开了高对比度或打印时，仍用原文颜色。
  - 扩展和用户脚本都能用；弹出页不加这一项。

## 其他
- 扩展的中文名改为「DualLens 双语对照翻译 · 沉浸式阅读」。

## 升级
- 扩展：商店版审核通过后会自动更新。Edge 商店版会从 1.2.0 直接更新到 1.3.0，同时带上 [v1.2.1](https://github.com/ray-oriental/duallens/releases/tag/v1.2.1) 的改动：没开文件访问也能打开本地 PDF、初始设置里的文件访问选项、阅读器面板改为浮层。
- 开发者模式：在扩展管理页点「重新加载」。
- 用户脚本：Tampermonkey 会照常自动更新到 1.3.0。

## 下载
- Microsoft Edge 加载项商店（审核通过后）。
- 开发者模式：`duallens-extension-v1.3.0.zip`；用户脚本：`duallens.user.js`。校验值见 `SHA256SUMS`。
