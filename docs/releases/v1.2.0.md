# DualLens v1.2.0 — 没分段的长文也能逐段对照，新增逐句对照

## 新内容
- **没分段的文字就近对照**：有些网页把整篇帖子或整章正文放在一个块里，只用单个换行分行，或者完全不分段，以前这一块的译文会全部堆在最后。默认的「按段对照」现在会拆开这样的块：
  - 用换行分开的行，一行原文配一行译文。
  - 被硬换行切断的半句，先拼回整句再翻译。
  - 诗歌、地址这类短行，仍然一行一对。
  - 超过约一屏（2,000 字符）的整块文字，每两三句跟一段译文。

  已经分好段的网页，排版不变。
- **逐句对照**：选这个模式后，正文每一句后面都跟着它的译文。入口在三个地方：
  - 弹出页「双语对照 / 仅译文」正下方的「按段对照 / 逐句对照」。
  - 用户脚本面板的同一位置。
  - 设置页「通用」里的「对照方式」。

  页面已经翻译时切换，会自动重新翻译。
- 只在文字之间或换行处拆分，链接、加粗这类行内元素不会被切开。显示原文时，网页会逐字节还原。

## 修复
- 用 `pre-wrap`、`pre-line`、`break-spaces` 排版的文字，翻译后原文的换行不再被合并成一行。

## 升级
- 扩展：商店版审核通过后会自动更新；开发者模式在扩展管理页点「重新加载」。
- 用户脚本：Tampermonkey 会自动检查更新，也可以重新安装 `duallens.user.js`。同版本的 `duallens-settings.js` 和 `duallens-features.js` 会一起获取。
