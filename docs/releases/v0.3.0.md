# DualLens v0.3.0 — PDF、字幕与文本翻译

继续使用自己的模型服务；历史兼容适配服务是可选增强。桌面 Chrome / Edge 扩展新增 PDF 阅读和文本侧栏，Android Edge + Tampermonkey 保留网页翻译并新增文本 / 字幕页签。

## 下载

- duallens-extension-v0.3.0.zip：浏览器扩展包，解压后在 chrome://extensions 或 edge://extensions 开启开发者模式并加载。
- duallens-edge-store-v0.3.0.zip：提交 Edge Add-ons 用的商店包（通过 `build_release.py --target edge-store` 生成，manifest 不含 key；不代表已上架）。
- duallens.user.js：Tampermonkey 用户脚本（Android Edge：菜单 → 扩展 → Tampermonkey，再打开本文件链接安装）。
- duallens-portable-v0.3.0.zip：扩展、可选历史兼容适配服务、文档、测试与脚本。
- SHA256SUMS：已生成资产的 SHA-256。

## 新内容

- PDF 双语阅读：桌面扩展内本地解析与渲染，附近段落显式翻译，支持可选择文本层、仅译文、恢复、缩放、页码跳转、本地文件与深浅主题。PDF 字节不发送给模型，只有选定段落文本进入用户的翻译服务。详见 [PDF.md](../PDF.md)。
- YouTube 双语字幕：翻译已有字幕轨，优先当前播放位置，跳转与 SPA 换视频会取消旧请求；恢复原生字幕。默认关闭，不提供语音识别。详见 [SUBTITLES.md](../SUBTITLES.md)。
- 文本翻译：桌面 Alt+S 或右键菜单打开侧栏，用户脚本使用文本页签；可选择语言、服务 / 模型，复制译文或调用系统朗读。
- 修复弹出页宽度与窄窗口布局。
- 加密配置迁移继续可用：桌面设置页提供本地二维码，手机端使用可复制加密文本。二维码与 PDF 模块不进入移动用户脚本，启动预算保持小于 400000 字节。字幕偏好随公共设置同步与备份。

## 已知限制

- PDF 仅桌面扩展；扫描件无文本层时不翻译。复杂跨栏 / 表格、外部 CMap、非内嵌标准字体及大型文档仍有限制。
- 字幕仅 YouTube 已有轨道；真实站点格式、签名地址与区域限制需实际验收。朗读依赖设备已安装的声音。
- Android Chrome 书签版、EPUB、文档翻译、视觉模型与 iframe 翻译尚未实现；见 [ROADMAP.md](../ROADMAP.md)。
- 离线 Chromium / GM 桩验证不能替代两台 Windows Chrome / Edge 与 Android 手机 / 平板真机验收。真实模型测试、最终安全验收、商店提交与发布由 leader / 用户单独完成。
