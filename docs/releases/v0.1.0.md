# DualLens v0.1.0 — 网页核心版

DualLens 第一版开源发布，采用 MIT 许可证，支持 Chrome / Edge Manifest V3。独立实现，不附带任何第三方翻译扩展源码、规则或品牌素材。

## 下载

- duallens-extension-v0.1.0.zip：浏览器扩展包，解压后选择包含 manifest.json 的目录加载。
- duallens-portable-v0.1.0.zip：扩展、本机标准库兼容适配服务、文档、测试和开发脚本。
- SHA256SUMS：两份 ZIP 的 SHA-256 校验值。
- GitHub 自动提供对应标签的完整 Source code。

## 使用

在 chrome://extensions 或 edge://extensions 开启开发者模式并「加载已解压的扩展程序」。首次使用先在设置选择模型并配置接口；也可选 Mock 演示交互，Mock 不是真实翻译。

支持网页段落双语／仅译文／恢复、链接和行内格式、懒翻译与动态内容、悬停／划词／输入框、15 种样式、缓存、术语表和提示词。默认不调用校园或订阅账户；可选后端需本机显式启用。订阅 CLI 集成目前面向 Windows，并受服务本身配额限制。

## 验证与限制

本机 131 项 Node 测试、18 项兼容适配服务测试通过。公开 CI 在 Windows / Ubuntu 验证离线逻辑，Ubuntu 浏览器使用 mock；标签对应的 CI 结果是发布验收依据。合成 Alt+A 不触发浏览器 commands 的探针仅记 INFO，命令路径另有功能覆盖。

第一版仅顶层网页；复杂真实站点仍需验证。PDF、EPUB、字幕、OCR、文档及 iframe 翻译尚未实现；未上架扩展商店。网页文本会发送给你选择的服务，请按自己的数据处理需求配置。

协作方式见 CONTRIBUTING.md：GitHub main 为基线，使用 feature branch／fork 与 PR，提交前跑 CI 同等离线检查。
