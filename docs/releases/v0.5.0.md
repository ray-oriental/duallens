# DualLens v0.5.0 — iframe 与 Shadow DOM 翻译、路径级站点规则、手机启动更快

## 翻译覆盖
- **iframe 内的文本也会翻译**：同源 iframe（含无 `src`、`about:blank`、`srcdoc`，如网页邮箱的邮件正文）由顶层页面统一扫描、注入样式并精确恢复；邮件切换时重写的 iframe 文档会自动重扫。电脑扩展还支持跨域 iframe：子 frame 里运行无界面的代理，跟随顶层页面的翻译/恢复/模式，状态由顶层推送，不轮询；不可见或很小的 frame（如广告位）不翻译。手机用户脚本只处理同源 iframe。
- **开放 Shadow DOM 里的文本也会翻译**（Web Components，如新版 Reddit），含嵌套 shadow、动态插入的组件；slot 投影的内容只翻一次。关闭的 shadow root 浏览器不允许访问，跳过。
- 扩展权限没有变化（只把内容脚本扩展到子 frame）。因为 `manifest.json` 变了，开发者模式安装的用户需要在扩展管理页点一次「重新加载」。

## 站点规则
- 规则可以按路径匹配：`mail.sjtu.edu.cn/zimbra/*`、`*.example.com/checkout/*`，可写协议与端口；多条命中时最具体的一条生效；旧的整站规则无需迁移。
- 每条规则可分别设置网页翻译（自动 / 从不 / 默认）、划词、悬停、输入框（开 / 关 / 默认）。「从不」只禁止自动翻译，仍可手动翻译。弹出页新增「仅当前路径」。
- 单页应用切换路由后重新判定规则（使用浏览器 Navigation API，不轮询）。

## 手机
- 用户脚本启动包从约 360 KB 降到 312 KB：设置面板拆成独立资源 `duallens-settings.js`，第一次打开设置时才加载，带 SHA-256 校验，由 Tampermonkey 在安装/更新时缓存。
- 修复：在普通 HTTP（非 HTTPS）页面上，浏览器没有 `crypto.subtle`，用户脚本会报错；现在自动改用纯 JS 的 SHA-256。

## 已知限制
- 真实 Zimbra 邮箱、两台 Windows 与 Android 真机尚待用户验证；本版验证为离线单测与 mock 浏览器测试（单测 412、扩展 E2E 33、用户脚本 11、iframe/Shadow DOM 4、版式 12、PDF 6、设置页 7）。
- 用户脚本不处理跨域 iframe。
