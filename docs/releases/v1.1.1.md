# DualLens v1.1.1 — 修复用户脚本在 Tampermonkey 5.5 里无法翻译

## 修复
- **用户脚本无法翻译**：在 Tampermonkey 5.5 里，v1.1.0 用户脚本的每个翻译请求都会在约 0.6 秒时被判超时，网页上每段只剩一个「↻」，免费机器翻译和自己接入的 AI 服务都受影响。原因是脚本用 `timeout: 0` 表示「不限时」，而 Tampermonkey 5.5 把 0 当作立即超时。现在不再传这个值，超时仍由 DualLens 自己控制。
- **不再弹出跨源授权页**：脚本头逐个列出内置翻译服务的域名，包括微软、Google、DeepL、OpenAI、DeepSeek、OpenRouter、本机 Ollama / LM Studio 和 OCR 语言包。Tampermonkey 不会再为这些域名另开标签页请你批准。你自己填写的服务地址仍会询问一次。
- **报错详情更具体**：脚本管理器拒绝请求、超时、域名解析失败或连接被拒时，提示里的「详情」会写明原因，不再只显示「没有更多技术信息」。

浏览器扩展（开发者模式或商店版）不经过 Tampermonkey，不受这个问题影响。这一版扩展没有功能变化，可以不升级。

## 升级
- 用户脚本：Tampermonkey 会自动检查更新，也可以直接重新安装 `duallens.user.js`。同版本的 `duallens-settings.js` 和 `duallens-features.js` 会一起获取。
- 扩展：无需操作。

## 下载
- 用户脚本：`duallens.user.js`。
- 开发者模式：`duallens-extension-v1.1.1.zip`。校验值见 `SHA256SUMS`。
