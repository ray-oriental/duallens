# PDF 双语阅读、导出与扫描页 OCR（待 leader 合并与最终验收）

桌面 Chrome / Edge 弹出页显式点击后，后台使用当前标签页 activeTab 读取 PDF，并打开 `pdf/viewer.html?token=<一次性令牌>`。阅读器从扩展来源 IndexedDB 原子读取并删除字节，同时移除地址栏令牌；未读记录最多三份，五分钟后逻辑过期并拒绝读取；这不等于届时已从 IndexedDB 删除。`?file=<URL 编码的地址>` 仍兼容其他来源，缺少授权时先显示来源授权按钮。PDF.js 在设备上解析和渲染，不把 PDF 字节传给翻译服务；用户显式点击翻译、确认 OCR 或导出后，文本块通过 `platform.translator().translateBatch`、service worker、缓存及用户配置的服务链翻译。普通阅读限视口及相邻页，导出依次处理所选范围。不发送 PDF URL、文件名、元数据或图片。

## 使用

1. 打开一个 PDF 标签页，在 DualLens popup 点击“用 DualLens 打开此 PDF”。URL 路径以 `.pdf` 结尾（支持查询参数与 fragment），或者按需探测响应的 `Content-Type` 为 `application/pdf` 时可用。未确认 PDF 时可从阅读页选择本地 PDF。
2. 宽屏默认“双栏对照”：左侧原页与可选择文本层，右侧同尺寸译文页。译文页复制原页画布，按原文字块坐标采样背景、逐行抹底、拟合字号并覆盖译文。左右页共用缩放和逐页滚动。可切换“仅译文页”“原文页”“重排阅读”；窄于 600 px 的扩展窗口首次打开默认重排。另有恢复原文、页码跳转和浅色/深色/跟随系统。
3. `file://` 链接需在浏览器扩展详情页开启“允许访问文件网址”。无需该权限也可在阅读页“选择本地 PDF”；选择的字节只在阅读页内存中处理。
4. 需要登录、带 URL 账号密码、重定向的链接不自动代取。先由用户下载，再选择本地文件。匿名 HTTP(S) 请求不带 cookie，不使用 API key。

自动打开 PDF 是可选增强，本轮未实现，保持浏览器原有行为；不添加 declarativeNetRequest 或重定向规则。

### 导出 PDF

工具栏「导出 PDF」展开一个小面板，默认「双栏对照」与「全部页」。双栏的每张输出页左侧是原页、右侧是同尺寸译文页；「仅译文页」保留原页尺寸。页码范围使用 `1-5, 8` 格式，自动排序去重，拒绝越界、倒序、空项与非整数。超过 50 页需再次勾选确认耗时与内存提示。

点「导出」后，尚未翻译的所选页依次经过现有首次发送确认、服务链和 `PdfTranslations`，允许处理视口外的所选页；已有终稿直接复用。面板显示「正在翻译第 3 / 12 页」及「正在生成 PDF」。可随时取消；取消、识别失败、翻译失败或编码失败都不会下载半成品。取消会终止尚未完成的请求，迟到结果不能重新触发下载。没有打印对话框，不需要 `downloads` 权限。

文件名为 `<原文件名>.bilingual.pdf` 或 `.translated.pdf`；缺少文件名时使用 `document`。URL 路径及本地文件选择器提供名称，名称只在本机使用；一次性交接的名称与 PDF 字节同样读取即删。导出最多保留 256 MiB 已编码内容，超过时请缩小范围。浏览器接到下载后，保存位置和最终保存结果由浏览器管理。

### 扫描页文字识别

没有文本层的页，或文字少于 60 字符且单个图像占页面面积超过 40% 的页，会让阅读器在工具栏下方显示一次「识别文字（本机 OCR）」入口。点击才展开语言与下载说明；仅检测不下载语言包，也不识别或翻译图像。确认识别后，本次阅读中的当前页及之后按需翻译、导出的扫描页自动识别；关闭阅读页即忘记此选择，不改图片文字开关或全局设置。

优先使用显式 PDF 源语言、文档语言元数据或本机文字语言检测结果；无法确定时用英语，可以在面板改成日语或韩语。复用现有 `eng / jpn / kor` 包，不新增语言数据或权限；目前没有中文 OCR 语言包。缺包或缓存校验失败时，面板先展示下载体积、来源域名和可在设置中删除的说明。用户勾选同意并点识别后，按需请求该来源权限；拒绝时不下载。已有包仍经过大小和 SHA-256 校验。页面图像只在本机的 Tesseract.js 5.1.1 / WASM 中处理，不发送给翻译服务。

PDF 识别使用整页自动分割，读取每行文字、归一化坐标及置信度。置信度至少 65 的行转换为与普通 PDF 相同的块；其余行保留原像素，不发送翻译。识别分块只在会话内存保存；译文遵循既有翻译缓存设置，语言包作为可删除资源存于扩展 IndexedDB。整页没有可靠文字或识别失败时，保留原页，在面板提示重试或更换语言。识别入口始终可用于重试当前页。默认不启用扫描页 OCR；未开启时，涉及扫描页的导出会说明先识别再重试。

## 实现与权限

- 交接缓存有逻辑过期与物理清理两个阶段：记录创建五分钟后，即使字节尚在 IndexedDB 中，也拒绝读取。后台每次初始化以及 `runtime.onStartup`、`runtime.onInstalled` 时清理所有过期条目；每次 `put()` 在同一事务内先清理再写入，每次 `take()` / `takeFile()` 也顺带清理全部过期条目。读取成功的目标记录在事务提交后、返回字节前已经删除，不能重放；未过期的其他记录保留（写入时最多三份的容量限制仍生效）。不申请 `alarms` 或其他新权限，不依赖 service worker 定时器；浏览器关闭、扩展禁用或没有活动上下文时，过期字节可能一直保留到下一次上述清理，不能承诺五分钟时严格物理删除。
- `background/pdf.js` 为 `pdf-status` / `pdf-open` 消息提供处理器。消息只使用实际 `tabId` 对应的 URL，不信任消息中的 PDF URL；只支持 HTTP、HTTPS、file，不接受 URL 用户名/密码。
- PDF 工具栏入口使用已有 activeTab，不需常驻 `<all_urls>`；其他来源由阅读器按钮按需 requestOrigin。本地文件选择不需主机权限。不使用 `webRequest`、`webRequestBlocking`、响应观察器或 PDF 标签页切换/更新监听，不扫描访问历史，不在启动或普通导航时探测 PDF。
- 只在 popup 打开时时先检查实际标签页 URL；`.pdf` 后缀无需网络探测。不确定的 HTTP(S) 地址发一次 HEAD；网络/HTTP 失败或没有 Content-Type 时，再发一次带 `Range: bytes=0-1023` 的 GET。每次请求超时 5 秒（两次失败最多约 10 秒），不重试、不跟随重定向、不带 cookie/认证、禁用 HTTP 缓存。读取响应头后立即取消响应体并中止请求，即使服务器忽略 Range 也不读取整份正文。成功的非 PDF HEAD 不触发 GET。不保留探测 URL 或结果缓存。
- PDF 下载 30 秒超时，流式限制 64 MiB；最多 2000 页。字节检查 PDF 标头。pdf.js 禁用 `isEvalSupported` 与 XFA；不创建注释/表单层、不执行 PDF 文档脚本或自动外链。加密 PDF 暂需先在本地解密。
- 页面通过 IntersectionObserver 在视口外 120% 的邻近范围解析/渲染，任务串行；翻译限视口内与前后各一页，不整本预翻译。最多保留五页原页画布/文本层及其译文底图，每张底图最多约四百万像素；远页释放画布，保留轻量分块数据和会话译文。离开范围的尚无结果请求可取消，重新靠近后再请求。
- `segments.js` 依据基线、行距、缩进、字号与栏位合并段落，单独保留目录点引导线、编号与页码；表格单元保守分离。`segment-worker.js` 在本地模块 Worker 中识别文本块；主线程分片创建页面、采样背景和插入译文。`layout.js` 用字符宽度估算断行并二分拟合字号；达到最小字号仍放不下时扩高并加 `data-overflow` 标记。复杂版面仍是启发式识别。
- 公式密集块、图片、页眉页脚、页码、旋转/RTL 字块保持原像素。行内公式作为 `<xN/>` 原子发送，译文中以本地原页裁图嵌回，并按实际字形收紧空白边界。模型若唯一、原样写回某个数学字面量，可据此恢复对应裁图；不猜测常见名字、纯数字、重复或丢失公式的位置。缺失、重复或非法公式占位符不抹掉原文。已有有效草稿时保留草稿，否则仅针对该块自动补试一次，仍失败显示可重试错误。表格线和图像没有被重新绘制，但与文字重叠的复杂图表仍需逐页检查。
- `translate.js: PdfTranslations` 独立于缩放保存状态，请求附加 `draft:true,purpose:'pdf'`。同一 id 的 `stage:'draft'` 可由 `stage:'final'`（或无 stage）替换；迟到草稿不覆盖终稿。精修失败保留草稿并注明。回调只解析为文本与受限公式原子，模型输出不进入 innerHTML。恢复取消请求、清除覆盖层并保留原页；旧请求、重试前的迟到结果不能写入新状态。
- `writer.js` 是仓库原创、无依赖的最小 PDF 1.4 写入器，以字节长度计算对象、流和 xref；JPEG 图像通过 `/DCTDecode` 嵌入。`ranges.js` 负责范围和安全文件名，`export-job.js` 保证全部页完成后才调用下载，并在退出时释放写入器。
- 导出逐页以约 150 DPI 渲染，单页限制 1200 万像素及最长边 8192 像素。借用屏幕相同的 `planBlock`、字号、背景采样和公式裁图创建短生命周期的不可交互排版节点；`raster.js` 按浏览器 Range 的真实断行、对齐和行内裁图位置画入 canvas，JPEG 质量为 0.94。及时清空逐页 canvas 和排版节点，只保留压缩图像。双栏直接嵌入两张图像，不再分配整张双宽 canvas。
- `pdf-ocr` 仅接受 `pdf/viewer.html` 扩展页面，携带 PNG base64、语言、随机 `jobId` 和会话内下载许可；不接收 URL。后台限制图像大小与并发，复用同一离屏文档。`pdf-ocr-cancel` 校验发起文档身份，取消下载和识别 Worker。离屏只接受本扩展后台发送的消息；漫画的既有分区检测路径保持不变。恢复原文、换文件、关闭页面或导出取消均屏蔽迟到结果。
- 纯链接、编号链接脚注和作者分组邮箱在本地识别并保留原样，不向服务发送。包含链接的正常正文仍翻译；短句不能仅因字数少就把漏翻当成功。
- 页首在 Abstract 之前且有机构/邮箱证据的短作者组、机构行使用本地 `identity` 分类，保留原像素，不发送翻译。姓名须符合大写词形且字号不大于机构行的 1.15 倍；普通标题与正文中的机构提及仍参与翻译。这是保守启发式，非拉丁作者、复杂合并分块仍需逐页核对。
  作者脚注同时识别 `* ∗ ⋆ † ‡`；包含姓名加邮箱的合并块、Google Brain/Research 机构行也作为证据。有 Abstract 时以其位置为边界，避免遗漏页高中部最后一组作者；无摘要仍用保守页首范围。姓名与机构须邻近，标题不因全为大写词形就被当成作者。
- 上述双阶段呈现需翻译服务及运行时端口支持阶段字段；本 PDF 分支不修改共享引擎或端口。仅有旧接口时仍显示普通终稿，实际双引擎链路由集成方验收。
- `pdfjs-dist` 5.4.624 源自 [npm tarball](https://registry.npmjs.org/pdfjs-dist/-/pdfjs-dist-5.4.624.tgz)，已校验 npm SHA-512，附 SHA-256、Apache-2.0 和 codec 许可证；[上游 release](https://github.com/mozilla/pdf.js/releases/tag/v5.4.624)。只执行打包到扩展内的模块，不从 CDN 执行代码。详见 `extension/vendor/pdfjs/VENDOR.md` 与同内容 `VENDOR.txt`。

## 移动端与已知限制

PDF.js 不进入 `duallens.user.js`。Android Edge + Tampermonkey 的建议路径是网站已经提供的 PDF.js 文本层，使用网页翻译或自行选取文本；本轮没有新增移动端 PDF 功能，也没有验证第三方 PDF.js 站点。Android Chrome 暂用系统 PDF 阅读器或复制文本到可翻译网页；不能声称手机原生 PDF 双语阅读已实现。

导出是图像版式，没有不可见文字层，不能搜索或复制导出件文字；不承诺 PDF/A、可访问性标签、矢量清晰度或交互表单保留。没有引入 pdf-lib 等新库。JPEG 对照片与体积友好，细小字和公式可能有压缩痕迹；极大页面会降低实际 DPI。文字仍可能因已有版式启发式而溢出，复杂版面需逐页核对。

扫描检测是保守启发式，空白页也可能出现识别入口；文字稀少且由多个小图拼成的扫描页可能漏检。OCR 只验证原创英文夹具；复杂多栏、日语、韩语、手写、旋转扫描、模糊照片与数学识别质量仍待真实文档验收。低置信度行会原样保留，不能把它们当作已经翻译。本轮最小包省略预打包 CMap 与非内嵌标准字体数据。多数内嵌字体和普通英文文本可读，但依赖外部 CMap 的东亚旧式 PDF 可能无法正确提取/渲染，需后续完整数据版本。复杂版面、极大图片、数千页文件的性能仍需真实文档验收。合成 Chromium 130 测试不能替代两台 Windows 上真实 Chrome / Edge 的验收。

## 离线验证

```powershell
npm test
python -B scripts/check_project.py
python -B scripts/build_release.py
python -B scripts/check_project.py --dist-dir dist
python -B tests/fixtures/generate_pdf.py
python -B -u tests/e2e/run_e2e.py --mock-only
python -B -u tests/e2e/run_pdf_e2e.py
```

PDF runner 复用 canonical staging / Session / run_case，临时 profile、原创八页英文 PDF、数学 PDF、两页纯图像英文扫描夹具、导出件、状态和截图位于 `DUALLENS_E2E_OUT`。默认仅 mock：验证同尺寸双栏、文字不越界/互叠、公式裁图、四视图、恢复原页 DOM、草稿到终稿的原位替换、恶意标记、迟到回调、缩放竞态、跳转/主题、画布上限、PDF 探测入口与本地选择器；新增真正下载两种 PDF 并用 pdf.js 回读页数、尺寸、图像对象和像素差异，取消零下载，以及真实 Tesseract 英文 OCR 后翻译并导出。交接缓存另用真实 IndexedDB 回读确认启动／安装和写入前清理、未过期条目保留、读取成功立即物理删除。单测另覆盖分块、字号、颜色、翻译状态机、xref 字节偏移、范围解析、低置信度过滤、取消清理及缓存生命周期。无匹配用例退出 2，失败退出 1。

OCR E2E 先按 `run_comics_e2e.py:ensure_fixture_downloads` 准备固定语言包，并另外复核英文包大小与 SHA-256；已准备缓存后可离线运行。Playwright 1.48 不可靠拦截离屏目标，因此只在隔离 staging 中将英文包的数据 URL 改为本机夹具服务器，哈希和大小保持不变；发布源码仍指向固定提交的 GitHub 数据。夹具由 `generate_pdf.py:make_scanned_pdf` 用标准库原创栅格字母生成，没有文本层或外部字体。

真实服务验收统一用 `run_acceptance.py`，见 [E2E README](../tests/e2e/README.md)。需明确授权，结果独立报告。
