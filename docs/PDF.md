# PDF 双语阅读、导出与扫描页 OCR（待 leader 合并与最终验收）

桌面 Chrome / Edge 中，弹出页显式点击「用 DualLens 打开此 PDF」后，在原标签页切换到阅读器；后退回到浏览器自带 PDF 阅读器。Alt+A 与现有右键「翻译此页 / 显示原文」在网页控制器不可用、确认当前页是 PDF 时走同一路径，并在文档加载后开始翻译，仍遵守首次发送确认；地址被浏览器隐藏的标签页（新标签页、浏览器内部页、未开文件访问的本地文件）不受快捷键和菜单影响。不新增菜单项，不自动接管 PDF。

2026-11-26 有窗口的 Edge 158 实测：焦点在内置 PDF 阅读器里时按 Alt+A 生效；内置阅读器的右键菜单是 Edge 自己的菜单，不显示任何扩展菜单项，所以 Edge 上的入口是工具栏图标和 Alt+A。

只在显式入口使用 activeTab，在顶层 ISOLATED world 读取 `{href, contentType}`；`application/pdf` 即确认，不依赖后缀、embed 或网络探测。点击打开后，用该标签页自己的登录状态读取当前地址，`credentials:'include'`、`cache:'force-cache'` 优先复用浏览器缓存，允许跟随响应重定向。字节校验 `%PDF-` 并限 64 MiB，临时存在随机键名的 isolated world 全局变量中，按每片 8 MiB 原始字节编码为 base64 交回后台；读取固定到原 documentId，末片及失败时清理，另有 60 秒兜底清理。注入被拒或读取失败时退回后台匿名读取；页内读取 30 秒没有新数据或总计 5 分钟即中止。超过大小限制直接拒绝，在新标签页显示 `notice=too-large` 的 64 MiB 限制说明，避免快捷键／菜单静默失败，不再尝试匿名下载。两条读取路径都失败时，在新标签页打开 `?notice=read-failed&name=<文件名>` 说明页，直接提供「选择本地 PDF」主按钮；原 PDF 标签页保持不动，一次性链接或表单提交生成的 PDF 不会因此丢失。

后台使用现有一次性交接缓存，以 `?token=<uuid>` 传给阅读器；读取即删、五分钟逻辑过期、至多三份未读记录。阅读器另将字节和文件名放入扩展来源 IndexedDB 阅读会话，sessionStorage 保存会话 id；URL 令牌消费后移除。刷新或后退再前进时从本机恢复，不再次请求原站。`?file=` 仍兼容独立来源，缺少授权时由按钮申请来源权限。PDF.js 只在设备上解析和渲染；翻译服务只收到用户请求翻译的文本块，不收到 PDF 字节、URL、文件名、元数据或图片。

## 不同浏览器设置下的行为

- **InPrivate／无痕**：先在扩展管理页允许 DualLens 在无痕窗口运行，再主动点击 PDF 入口。2026-11-26 的 Edge 158.0.4370.33 与 Chrome 158.0.8127.36 实测：默认 spanning 模式下，原地切换虽返回成功，文档实际显示 `ERR_BLOCKED_BY_CLIENT`。因此无痕来源保留原 PDF，另开阅读器；浏览器实际将阅读器放在普通窗口。`private=1` 把私密来源传到阅读器，即使窗口标志为普通也不读写阅读会话、不读写译文缓存。消费令牌后地址栏清空参数，只在标签页 sessionStorage 留布尔标志；若该存储不可用则保留 `private=1`，避免刷新丢失隐私状态。刷新后显示「无痕窗口里的 PDF 不保存在本机，刷新后请重新打开。」手选文件仍沿用该私密状态。原有五分钟、一次性、读取即删的临时交接保持不变，不承诺这段交接从不触及磁盘。
- **阻止第三方 Cookie／跟踪防护**：当前 PDF 的页内读取仍是原标签页的同源请求，沿用该标签页登录态，不要求放宽 Cookie 或跟踪防护设置。站点本身无法加载 PDF、链接失效或禁止重读时，说明页提供本地选择器，原 PDF 保留；不会要求关闭隐私保护。
- **已授予所有网站权限／网站访问设为「单击时」**：都先用当前标签页读取 PDF；已有广泛权限不会把读取改为匿名下载。单击时依靠这次工具栏操作获得 activeTab，无需永久授予所有网站权限。
- **DualLens 非默认设置**：仅译文模式映射为阅读器的「仅译文页」，目标语言沿用设置；普通来源刷新恢复文档和视图。网页译文颜色按 DESIGN／SPEC 的既有约定不影响 PDF，选择非自动颜色也不会阻止打开或改变 PDF 配色。
- **Edge「始终下载 PDF 文件」**：浏览器会下载文件，没有 PDF 标签页可切换。请先打开下载的文件，或在 DualLens 阅读器选择本地 PDF；未授予文件访问时使用文件选择器。

回归脚本 `tests/e2e/run_edge_pdf_entry.py` 在全新临时 profile 中逐一运行默认、第三方 Cookie 阻止（Edge 同时严格跟踪防护）、所有网站权限、单击时访问、无痕和非默认设置，覆盖 auth／noext／gone 与刷新。`--chrome` 使用独立 Chrome profile，`--variant` 可单独重跑；任何首选项或 API 不可用会明确报告未覆盖。无痕弹出页在 headless 模式以普通扩展文档模拟，仅将 active-tab 查询映射到真实无痕来源；activeTab 仍通过真实 `Extensions.triggerAction` 授予。

## 使用

1. 打开一个 PDF 标签页，在 DualLens popup 点击“用 DualLens 打开此 PDF”。优先识别当前顶层文档的 PDF 类型，支持无后缀、查询参数、登录态及已重定向的 PDF；注入失败时才按后缀或匿名 HEAD/Range 探测识别。未确认 PDF 时可从阅读页选择本地 PDF。
2. 宽屏默认“双栏对照”：左侧原页与可选择文本层，右侧同尺寸译文页。译文页复制原页画布，按原文字块坐标采样背景、逐行抹底、拟合字号并覆盖译文。左右页共用缩放和逐页滚动。可切换“仅译文页”“原文页”“重排阅读”；窄于 600 px 的扩展窗口首次打开默认重排。另有恢复原文、页码跳转和浅色/深色/跟随系统。
3. 本地 PDF 有两条路：已开启“允许访问文件网址”且浏览器提供当前 PDF 地址时，弹出页一键打开；未开启时，进入阅读器后按“选择本地 PDF”选择同一文件，不必授予权限。说明会显示可取得的文件名，并提供扩展详情页入口，方便以后开启一键打开。选择的字节只在本机解析并保存到有上限的阅读会话缓存。
4. 登录态 PDF 优先从当前标签页读取；失效的一次性链接、站点限制、已退出登录仍可能读不到，可下载后选择本地文件。不接受 URL 中嵌入账号密码的地址。后台备用 HTTP(S) 请求仍匿名、不跟随重定向，不使用 API key。

自动打开 PDF 是可选增强，本轮未实现，保持浏览器原有行为；不添加 declarativeNetRequest 或重定向规则。

Edge 156 与 Chrome 155 实测：文件访问关闭时，即使点击扩展图标，浏览器也不提供当前标签页的地址和标题；设置页、空白页也可能隐藏相同信息，不能据此断言当前页是 PDF。此时弹出页不显示“此 PDF”按钮；受限说明下直接提供“打开本地 PDF”文字按钮，再在阅读器选择文件即可。Alt+A / 现有右键页翻译入口在地址隐藏且没有文件权限时同样进入选择器，不报“不是 PDF”。

初始设置在翻译方式后提供「本地 PDF」选择（仅扩展且文件访问尚未开启时显示），默认「暂不开启」。选「开启」并点下一步，先保存本机进度再打开当前安装的扩展详情页，由你手动打开开关；浏览器不允许扩展代为开启。重新打开弹出页从「准备就绪」继续，并显示实际状态；完成或跳过后清除进度。设置 → 数据与隐私也有常驻「本地 PDF」状态与详情页按钮，从详情页回来会更新状态。开关仅用于在本地 PDF 上主动点击 DualLens 后读取那一个文件；文件不会上传，翻译时只有文字发往所选服务。用户脚本不显示此选择或设置。

如需以后一键打开：Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，找到本次使用的 DualLens → 详情 → 开启“允许访问文件网址”。阅读器的“打开扩展详情页”可直达当前安装的详情页；商店版与开发版是各自独立的安装，需分别设置。不申请 `tabs` 或所有网站权限。

2026-11-26 隔离 profile 实测 Edge 158 / Chrome 158：登录态、无后缀、查询参数与重定向均可原地切换；刷新、后退再前进恢复八页夹具。约 40 MiB 的原创夹具以六片完成交接。`Content-Security-Policy: sandbox` 的 PDF 在这两版浏览器仍能标签页内读取；测试另模拟读取注入被拒，确认可退回后台匿名读取。headless 的快捷键／菜单回归调用二者共用的处理函数，不代表真实按键或原生菜单可见性验收。

### 阅读会话与尽力清理

交接令牌、本地选择器与 `?file=` 三种来源均在 PDF.js 接收并转移缓冲区之前保存字节。每条最多 64 MiB，至多三条，换文件覆盖同一会话；超出容量删最旧写入记录，24 小时逻辑过期。sessionStorage 与标签页绑定，正常关闭标签页后不再保留恢复入口；复制标签页继承的会话在下次写入时另建 id。

后台初始化、启动、安装／更新和每次写入清理过期会话，读取时也拒绝并清理过期项；`tabs.onRemoved` 按记录的 tabId 删除对应会话。这些都是尽力清理：浏览器崩溃、强制退出、扩展禁用或没有活动上下文时，物理字节可能保留到下一次清理。不能承诺关页时或满 24 小时时一定立即从磁盘删除。缓存失败会提示刷新可能需要重选文件；记录被淘汰或过期时提示重新选择。会话不进入同步区或配置导出，不上传。

### 导出 PDF

工具栏「导出 PDF」在按钮下方弹出一个浮层，默认「双栏对照」与「全部页」。浮层盖在页面上，不撑高工具栏；按 Esc 或再点按钮关闭；点工具栏或页面也会关闭，但导出进行中保持打开。双栏的每张输出页左侧是原页、右侧是同尺寸译文页；「仅译文页」保留原页尺寸。页码范围使用 `1-5, 8` 格式，自动排序去重，拒绝越界、倒序、空项与非整数。超过 50 页需再次勾选确认耗时与内存提示。

点「导出」后，尚未翻译的所选页依次经过现有首次发送确认、服务链和 `PdfTranslations`，允许处理视口外的所选页；已有终稿直接复用。面板显示「正在翻译第 3 / 12 页」及「正在生成 PDF」。可随时取消；取消、识别失败、翻译失败或编码失败都不会下载半成品。取消会终止尚未完成的请求，迟到结果不能重新触发下载。没有打印对话框，不需要 `downloads` 权限。

文件名为 `<原文件名>.bilingual.pdf` 或 `.translated.pdf`；缺少文件名时使用 `document`。URL 路径及本地文件选择器提供名称，名称只在本机使用；一次性交接的名称与 PDF 字节同样读取即删。导出最多保留 256 MiB 已编码内容，超过时请缩小范围。浏览器接到下载后，保存位置和最终保存结果由浏览器管理。

### 扫描页文字识别

没有文本层的页，或文字少于 60 字符且单个图像占页面面积超过 40% 的页，会让阅读器在工具栏下方显示一次「识别文字（本机 OCR）」入口。点击才展开语言与下载说明；仅检测不下载语言包，也不识别或翻译图像。确认识别后，本次阅读中的当前页及之后按需翻译、导出的扫描页自动识别；关闭阅读页即忘记此选择，不改图片文字开关或全局设置。

优先使用显式 PDF 源语言、文档语言元数据或本机文字语言检测结果；无法确定时用英语，可以在面板改成日语或韩语。复用现有 `eng / jpn / kor` 包，不新增语言数据或权限；目前没有中文 OCR 语言包。缺包或缓存校验失败时，面板先展示下载体积、来源域名和可在设置中删除的说明。用户勾选同意并点识别后，按需请求该来源权限；拒绝时不下载。已有包仍经过大小和 SHA-256 校验。页面图像只在本机的 Tesseract.js 5.1.1 / WASM 中处理，不发送给翻译服务。

PDF 识别使用整页自动分割，读取每行文字、归一化坐标及置信度。置信度至少 65 的行转换为与普通 PDF 相同的块；其余行保留原像素，不发送翻译。识别分块只在会话内存保存；译文遵循既有翻译缓存设置，语言包作为可删除资源存于扩展 IndexedDB。整页没有可靠文字或识别失败时，保留原页，在面板提示重试或更换语言。识别入口始终可用于重试当前页。「识别文字（本机 OCR）」同样是状态行下方的浮层，识别成功后自动收起，识别中保持打开。默认不启用扫描页 OCR；未开启时，涉及扫描页的导出会说明先识别再重试。

## 实现与权限

- 交接缓存有逻辑过期与物理清理两个阶段：记录创建五分钟后，即使字节尚在 IndexedDB 中，也拒绝读取。后台每次初始化以及 `runtime.onStartup`、`runtime.onInstalled` 时清理所有过期条目；每次 `put()` 在同一事务内先清理再写入，每次 `take()` / `takeFile()` 也顺带清理全部过期条目。读取成功的目标记录在事务提交后、返回字节前已经删除，不能重放；未过期的其他记录保留（写入时最多三份的容量限制仍生效）。不申请 `alarms` 或其他新权限，不依赖 service worker 定时器；浏览器关闭、扩展禁用或没有活动上下文时，过期字节可能一直保留到下一次上述清理，不能承诺五分钟时严格物理删除。
- `background/pdf.js` 为 `pdf-status` / `pdf-open` 消息提供处理器。消息只使用实际 `tabId` 对应的 URL，不信任消息中的 PDF URL；只支持 HTTP、HTTPS、file，不接受 URL 用户名/密码。
- `pdf-status` 对已识别的本地 PDF 另返回 `requiresFileSelection`。缺少文件权限时 `pdf-open` 不读取文件，原地切换到 `?notice=file-access&name=<可选文件名>`；不传递完整本地路径。显式选择器消息 `pdf-open-local` 同样仅接受扩展页面，使用实际标签页的可用文件名。说明参数保留至选择文件成功，便于刷新后仍显示操作说明；文件名仅以文本显示，选择成功后收起说明。
- PDF 工具栏入口使用已有 activeTab，不需常驻 `<all_urls>`；其他来源由阅读器按钮按需 requestOrigin。本地文件选择不需主机权限。不使用 `webRequest`、`webRequestBlocking`、响应观察器或 PDF 标签页切换/更新监听，不扫描访问历史，不在启动或普通导航时探测 PDF。
- 显式入口优先注入只读类型识别；注入成功且非 PDF 时不探测。仅注入失败时检查实际标签页 URL；`.pdf` 后缀无需网络探测。弹出页、快捷键和菜单从不发网络探测；只有直接调用 `pdf-status` 并显式要求 `probe:true` 时，不确定的 HTTP(S) 地址才发一次 HEAD；网络/HTTP 失败或没有 Content-Type 时，再发一次带 `Range: bytes=0-1023` 的 GET。每次请求超时 5 秒（两次失败最多约 10 秒），不重试、不跟随重定向、不带 cookie/认证、禁用 HTTP 缓存。读取响应头后立即取消响应体并中止请求，即使服务器忽略 Range 也不读取整份正文。成功的非 PDF HEAD 不触发 GET。不保留探测 URL 或结果缓存。
- PDF 下载 30 秒超时，流式限制 64 MiB；最多 2000 页。字节检查 PDF 标头。pdf.js 禁用 `isEvalSupported` 与 XFA；不创建注释/表单层、不执行 PDF 文档脚本或自动外链。加密 PDF 暂需先在本地解密。
- 页面通过 IntersectionObserver 在视口外 120% 的邻近范围解析/渲染，任务串行；翻译限视口内与前后各一页，不整本预翻译。最多保留五页原页画布/文本层及其译文底图，每张底图最多约四百万像素；远页释放画布，保留轻量分块数据和会话译文。离开范围的尚无结果请求可取消，重新靠近后再请求。
- `segments.js` 依据基线、行距、缩进、字号与栏位合并段落，单独保留目录点引导线、编号与页码；表格单元保守分离。`segment-worker.js` 在本地模块 Worker 中识别文本块；主线程分片创建页面、采样背景和插入译文。`layout.js` 用字符宽度估算断行并二分拟合字号；达到最小字号仍放不下时扩高并加 `data-overflow` 标记。复杂版面仍是启发式识别。
- 公式密集块、图片、页眉页脚、页码、旋转/RTL 字块保持原像素。行内公式作为 `<xN/>` 原子发送，译文中以本地原页裁图嵌回，并按实际字形收紧空白边界。模型若唯一、原样写回某个数学字面量，可据此恢复对应裁图；不猜测常见名字、纯数字、重复或丢失公式的位置。缺失、重复或非法公式占位符不抹掉原文。已有有效草稿时保留草稿，否则仅针对该块自动补试一次，仍失败显示可重试错误。表格线和图像没有被重新绘制，但与文字重叠的复杂图表仍需逐页检查。
- `translate.js: PdfTranslations` 独立于缩放保存状态，请求附加 `draft:true,purpose:'pdf'`。同一 id 的 `stage:'draft'` 可由 `stage:'final'`（或无 stage）替换；迟到草稿不覆盖终稿。精修失败保留草稿并注明。回调只解析为文本与受限公式原子，模型输出不进入 innerHTML。恢复取消请求、清除覆盖层并保留原页；旧请求、重试前的迟到结果不能写入新状态。
- `writer.js` 是仓库原创、无依赖的最小 PDF 1.4 写入器，以字节长度计算对象、流和 xref；JPEG 图像通过 `/DCTDecode` 嵌入。`ranges.js` 负责范围和安全文件名，`export-job.js` 保证全部页完成后才调用下载，并在退出时释放写入器。
- 导出逐页以约 150 DPI 渲染，单页限制 1200 万像素及最长边 8192 像素。借用屏幕相同的 `planBlock`、字号、背景采样和公式裁图创建短生命周期的不可交互排版节点；`raster.js` 按浏览器 Range 的真实断行、对齐和行内裁图位置画入 canvas，JPEG 质量为 0.94。及时清空逐页 canvas 和排版节点，只保留压缩图像。双栏直接嵌入两张图像，不再分配整张双宽 canvas。
- `pdf-ocr` 仅接受 `pdf/viewer.html` 扩展页面，携带 PNG base64、语言、随机 `jobId` 和会话内下载许可；不接收 URL。后台限制图像大小与并发，复用同一离屏文档。`pdf-ocr-cancel` 校验发起文档身份，取消下载和识别 Worker。离屏只接受本扩展后台发送的消息；漫画的既有分区检测路径保持不变。恢复原文、换文件、关闭页面或导出取消均屏蔽迟到结果。
- 纯链接、编号链接脚注和作者分组邮箱在本地识别并保留原样，不向服务发送。包含链接的正常正文仍翻译；短句不能仅因字数少就把漏翻当成功。
- 页首在 Abstract 之前且有机构/邮箱证据的短作者组、机构行使用本地 `identity` 分类，保留原像素，不发送翻译。姓名须符合大写词形且字号不大于机构行的 1.15 倍；普通标题与正文中的机构提及仍参与翻译。这是保守启发式，非拉丁作者、复杂合并分块仍需逐页核对。
  作者脚注同时识别 `* ∗ ⋆ † ‡`；包含姓名加邮箱的合并块、Google Brain/Research 机构行也作为证据。有 Abstract 时以其位置为边界，避免遗漏页高中部最后一组作者；无摘要仍用保守页首范围。姓名与机构须邻近，标题不因全为大写词形就被当成作者。
- 上述双阶段呈现需翻译服务及运行时端口支持阶段字段；本 PDF 分支不修改共享引擎或端口。仅有旧接口时仍显示普通终稿，实际双引擎链路由集成方验收。
- `pdfjs-dist` 5.4.624 源自 [npm tarball](https://registry.npmjs.org/pdfjs-dist/-/pdfjs-dist-5.4.624.tgz)，已校验 npm SHA-512，附 SHA-256、Apache-2.0 和 codec 许可证；[上游 release](https://github.com/mozilla/pdf.js/releases/tag/v5.4.624)。只执行打包到扩展内的模块，不从 CDN 执行代码。详见 `extension/vendor/pdfjs/VENDOR.md` 与同内容 `VENDOR.txt`。

## 移动端与已知限制

PDF.js 不进入 `duallens.user.js`。Android Edge + Tampermonkey 的建议路径是网站已经提供的 PDF.js 文本层，使用网页翻译或自行选取文本；本轮没有新增移动端 PDF 功能，也没有验证第三方 PDF.js 站点。Android Chrome 暂用系统 PDF 阅读器或复制文本到可翻译网页；不能声称手机原生 PDF 双语阅读已实现。

导出是图像版式，没有不可见文字层，不能搜索或复制导出件文字；不承诺 PDF/A、可访问性标签、矢量清晰度或交互表单保留。没有引入 pdf-lib 等新库。JPEG 对照片与体积友好，细小字和公式可能有压缩痕迹；极大页面会降低实际 DPI。文字仍可能因已有版式启发式而溢出，复杂版面需逐页核对。

扫描检测是保守启发式，空白页也可能出现识别入口；文字稀少且由多个小图拼成的扫描页可能漏检。OCR 只验证原创英文夹具；复杂多栏、日语、韩语、手写、旋转扫描、模糊照片与数学识别质量仍待真实文档验收。低置信度行会原样保留，不能把它们当作已经翻译。本轮最小包省略预打包 CMap 与非内嵌标准字体数据。多数内嵌字体和普通英文文本可读，但依赖外部 CMap 的东亚旧式 PDF 可能无法正确提取/渲染，需后续完整数据版本。复杂版面、极大图片、数千页文件的性能仍需真实文档验收。合成 Chromium 130 测试不能替代两台 Windows 上真实 Chrome / Edge 的验收。

## 离线验证

```powershell
npm test
python -B scripts/check_project.py
python -B scripts/build_release.py
python -B scripts/check_project.py --dist-dir dist
python -B tests/fixtures/generate_pdf.py
python -B -u tests/e2e/run_e2e.py --mock-only
python -B -u tests/e2e/run_pdf_e2e.py
```

PDF runner 复用 canonical staging / Session / run_case，临时 profile、原创八页英文 PDF、数学 PDF、两页纯图像英文扫描夹具、导出件、状态和截图位于 `DUALLENS_E2E_OUT`。默认仅 mock：验证同尺寸双栏、文字不越界/互叠、公式裁图、四视图、恢复原页 DOM、草稿到终稿的原位替换、恶意标记、迟到回调、缩放竞态、跳转/主题、画布上限、PDF 探测入口与本地选择器；新增真正下载两种 PDF 并用 pdf.js 回读页数、尺寸、图像对象和像素差异，取消零下载，以及真实 Tesseract 英文 OCR 后翻译并导出。交接缓存另用真实 IndexedDB 回读确认启动／安装和写入前清理、未过期条目保留、读取成功立即物理删除。单测另覆盖分块、字号、颜色、翻译状态机、xref 字节偏移、范围解析、低置信度过滤、取消清理及缓存生命周期。无匹配用例退出 2，失败退出 1。

OCR E2E 先按 `run_comics_e2e.py:ensure_fixture_downloads` 准备固定语言包，并另外复核英文包大小与 SHA-256；已准备缓存后可离线运行。Playwright 1.48 不可靠拦截离屏目标，因此只在隔离 staging 中将英文包的数据 URL 改为本机夹具服务器，哈希和大小保持不变；发布源码仍指向固定提交的 GitHub 数据。夹具由 `generate_pdf.py:make_scanned_pdf` 用标准库原创栅格字母生成，没有文本层或外部字体。

本机手动运行 `tests/e2e/run_edge_local_pdf.py`（不进 CI，Edge 不存在时 SKIP）；`--chromium` 使用 Playwright Chromium 对照，`--chrome` 使用独立临时 Chrome。脚本仅加载去掉 manifest key 的源码副本，把仓库夹具复制到中文和空格路径，开关文件权限并核对实际标签页信息、阅读器和详情页。profile 位于专用 E2E 缓存，用后删除；输出把完整夹具路径替换为占位符。Edge 通过 `Extensions.triggerAction` 授予真实 activeTab；headless 模式不暴露工具栏弹出页 target，因此在同一授权下以不激活的标签页加载 popup 文档。Chromium 130 没有该动作协议，快捷键尝试无效时明确跳过真实一键打开对照。PDF runner 另用无额外主机授权的 staging 验证地址隐藏分支，用常规 staging 验证地址可见但文件权限关闭的分支。

真实服务验收统一用 `run_acceptance.py`，见 [E2E README](../tests/e2e/README.md)。需明确授权，结果独立报告。
