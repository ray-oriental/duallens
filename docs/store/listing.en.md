# Edge Add-ons store listing (English)

## Short description (≤132 characters)

Read webpages bilingually with your chosen model service, while preserving layout and keeping privacy controls local.

## Detailed description

DualLens adds paragraph-level bilingual, translation-only, and restore-original views to webpages. Configure your own OpenAI-compatible service or an optional local gateway; webpage text is sent only to the service you explicitly choose. API keys stay on this browser and are never synced or used for telemetry. The desktop extension supports Chrome and Edge. On Android Edge, use the userscript from the Release with Tampermonkey.

This release focuses on webpages. PDF, EPUB, subtitles, OCR, documents, and iframe translation are not implemented.
