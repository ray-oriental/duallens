# Edge Add-ons store listing (English)

## Short description (≤132 characters)

Read webpages bilingually with your chosen model service, while preserving layout and keeping privacy controls local.

## Detailed description

DualLens adds paragraph-level bilingual, translation-only and restore-original views. The v0.4 default uses free machine translation without a key, with optional refinement through your own OpenAI-compatible service or local gateway. Failed refinement keeps the machine translation. Default Microsoft/Google endpoints are unofficial and may change or fail; translation actions send them the requested text. Settings can select official keyed engines, disable MT fallback, or disable MT with LLM-only mode. API keys stay local, outside sync and telemetry. Desktop supports Chrome and Edge; Android Edge uses the Release userscript with Tampermonkey.

This release focuses on webpages. PDF, EPUB, subtitles, OCR, documents, and iframe translation are not implemented.
