# Edge Add-ons 商店文案（中文）

## 简短描述（≤132 字符）

网页双语对照翻译：使用你选择的模型服务，保留原文排版与隐私控制。

## 详细描述

DualLens 为网页提供段落级双语对照、仅译文和恢复原文。v0.4 默认先用免费机器翻译，无需 key；可填写自己的 OpenAI 兼容服务后台精修，或使用可选本机网关。精修失败保留机器译文。默认 Microsoft / Google 是非官方接口，可能变动或失效；用户触发翻译后会收到待译文字。设置可更换官方带 key 引擎、关闭 MT 备用或切换「只大模型」以禁用 MT。API key 只存当前浏览器本机，不同步、不遥测。支持 Chrome 与 Edge 桌面扩展；Android Edge 使用 Release 用户脚本与 Tampermonkey。

当前版本聚焦网页内容，不包含 PDF、EPUB、字幕、OCR、文档或 iframe 翻译。
