# Edge Add-ons 商店文案（中文）

## 简短描述（≤132 字符）

网页双语对照翻译：使用你选择的模型服务，保留原文排版与隐私控制。

## 详细描述

DualLens 为网页提供段落级双语对照、仅译文和恢复原文。你可以填写自己的 OpenAI 兼容服务，或使用本地可选网关；网页文本只发送到你明确选择的服务。API key 只保存在当前浏览器本机，不同步、不遥测。支持 Chrome 与 Edge 桌面扩展；Android Edge 请使用 Release 中的用户脚本与 Tampermonkey。

当前版本聚焦网页内容，不包含 PDF、EPUB、字幕、OCR、文档或 iframe 翻译。
