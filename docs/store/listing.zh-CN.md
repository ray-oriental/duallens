# DualLens 双语对照翻译

网页双语对照翻译。默认安静，无需账号，没有遥测；文字只发给你选择的翻译服务。

DualLens 在每个段落下方显示译文，让你用两种语言同时阅读。可随时切换为仅译文，或恢复原文。

默认安静
• 在你主动触发之前，页面上不会多出任何东西：点工具栏按钮、按 Alt+A，或用右键菜单。
• 更多功能默认全部关闭，需要时在弹出页打开：悬浮按钮、划词、悬停、输入框翻译、视频字幕、图片文字。
• 没有欢迎页、没有角标、没有广告。

按你的方式翻译
• 开箱即用的免费机器翻译，无需账号和密钥。
• 可选：接入你自己的 AI 服务精修——OpenAI、DeepSeek、OpenRouter、本地模型（Ollama、LM Studio）或任何兼容 OpenAI 的接口。费用由你和服务商直接结算。
• 还包括：PDF 并排对照、HTML5 视频与 YouTube 双语字幕、文本翻译侧栏、按网站设置规则、术语表。
• 界面提供简体中文与英文，在设置「常用」顶部切换；译文的目标语言单独设置。

你的数据
• DualLens 没有自己的账号体系、统计或服务器，开发者收不到任何内容。
• 翻译时，文字由你的浏览器直接发给你选择的服务。默认是微软的免费机器翻译端点，失败时改用谷歌。这些是非官方、未公开承诺的接口：可能随时变动或失效，对文字的处理由各自条款决定，DualLens 与微软、谷歌没有隶属或背书关系。你可以改用需要密钥的官方引擎、关闭备用，或只使用 AI 服务。
• 第一次向某个服务发送文字之前，上手、设置或当前翻译工具会先说明去向，由你确认。本机上的本地模型无需确认。
• API 密钥只保存在这台设备上。译文缓存与设置保存在浏览器里，可随时清除。
• 详情：https://github.com/ray-oriental/duallens/blob/main/docs/PRIVACY.md

权限
• 安装时只需要访问翻译服务的地址。网页内容通过 "activeTab" 按需读取。只有当你打开必须在点击前就存在于页面的功能时，才会请求访问所有网站的权限，并可随时撤销。
