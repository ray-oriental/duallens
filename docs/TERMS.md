## 状态与流程约定

- 快捷键必须来自 `chrome.commands.getAll()`，顺序为网页翻译、显示方式、输入框翻译、文本翻译。未绑定时不显示快捷键。上手页不再承诺固定 `Alt+A`；用户脚本提示通过 Tampermonkey 菜单操作。
- 异步按钮使用 `ui/forms/feedback.js`：进行中禁用、替换按钮文案，结束后恢复；结果带本机时间，`aria-live="polite"`，遵从减少动效偏好。网页命令的确认只表示「已发送操作」，实际完成程度仍由页面进度显示。
- 常用与更多功能的普通选项即时保存；AI 服务、网站规则、术语表与图片网站列表保留明确的保存/取消。图片网站列表下单独说明保存要求；输入框/悬停的模型名称现在按其他选项即时保存。
- 即时保存的进行中状态与显式保存草稿分开记录；切换分组或关闭面板前等待已发起的即时保存结束，不将其误报成未保存草稿，也不清除真正的草稿。
- 设置保存成功仍只使用标题行的「已保存」，不在底部重复输出。测试、导入、导出和失败使用状态行。术语文件导入先完整校验、放入草稿，保存后生效；导出当前有效草稿，不会偷偷保存其他修改。
- 弹出页切换目标语言后说明已翻译页面会重新翻译；网站规则保存后说明当前页即时生效。两者复用现有内容脚本的设置订阅，不另发重复翻译命令。
- 用户脚本面板的 Tab 包括导航链接和折叠项，限制在当前对话框内；Esc 优先关闭内层确认，再关闭面板，关闭后恢复先前焦点。焦点圈沿用键盘操作约定，不新增样式。
- 文本翻译的翻译/复制复用异步反馈。清空保留语言选择，清除输入、译文和检测记录；交换语言时，有译文则将其放入输入区，没有则保留原输入，均需再次点击翻译才发送。自动检测调用平台本地接口，不增加远程检测服务；不可靠、未知或不支持的检测结果不能用于交换。
- 侧栏 Esc 取消等待并丢弃迟到结果，不关闭侧栏；手机文本面板翻译中先取消，空闲时 Esc 仍按面板规则关闭。底层现有 `translate-text` 单次 RPC 没有传输取消协议，已发送请求可能继续完成，UI 不再接收其结果；未同意的发送确认可通过取消阻止发送。本轮不越界修改传输协议。

## 走查与实现边界

- 页面内悬浮按钮、划词、悬停、输入框、字幕、图片文字与首次发送确认：只读检查交互实现并跑既有 E2E；统一可共用的词典术语，不修改内容模块。
- 侧栏：leader 已扩展 `extension/sidepanel/**` 文件边界；本轮完成文本翻译反馈、清空、交换语言、本地检测与 Esc 取消，并补中英测试与截图。
- PDF：阅读器的原文与译文状态、打开与关闭按现状检查；仍含「恢复 PDF」等旧动作名，交给 PDF 负责人一并处理，不改其源码。
- 「跳过上手」保留已经选过的目标语言；leader 确认保留此行为，PRODUCT.md 已同步修正。

## 承诺 → 现状 → 处理

| 产品 / 规格承诺 | 走查现状 | 本轮处理 |
| --- | --- | --- |
| 默认安静；附加功能关闭 | 默认值与已有新安装 E2E 覆盖一致 | 保持默认值，不新增页面入口 |
| 同一动作同名、快捷键可修改 | 菜单有「恢复当前页面」，上手与关于页写死快捷键 | 统一词典与菜单测试；上手、主按钮、关于页使用实际绑定，未绑定不展示 |
| 异步动作可预期 | 设置已有助手，popup 和侧栏原先各自实现 | popup/上手及侧栏翻译/复制均复用反馈助手 |
| 普通选项即时保存 | 模型名无可见保存按钮，图片网站列表只有草稿 | 模型名即时保存；图片网站列表增加保存/取消；避免未改语言的存储通知重绘正在保存的控件 |
| 网站规则可逐条编辑 | 改匹配地址会留下旧规则，无逐条删除入口 | 改为原条目重命名，冲突时保留草稿；增加删除，回读验证 |
| 术语表可编辑并随配置迁移 | 仅有文本编辑和全配置导入导出，无独立术语文件流程 | 增加 TSV/逐行术语导入导出；校验后暂存，保存才生效；空表有说明 |
| 本站改动立即生效 | 内容脚本已经订阅设置，popup 无完成说明 | 保留订阅机制，补保存/生效提示与存储测试 |
| 改目标语言后重新翻译 | 内容脚本已有重译逻辑，popup 没有说明 | 提示已翻译页面将重新翻译，避免发第二次命令 |
| 键盘可关闭面板、顺序合理 | 手机面板 Tab 跳过链接/summary，Esc 可能关闭外层 | 补导航与折叠项；内层确认优先取消，并验证草稿保留 |
| 文本翻译复制/清空/交换语言 | 已增加共享反馈、清空和交换；自动模式用本地检测结果 | leader 授权扩展边界后完成；Esc 取消等待并防止迟到结果回写 |
| 上手跳过保留已选内容 | 目标语言保留，其余选项沿用当前值或默认值 | 按 leader 决定保留行为，并修正 PRODUCT.md，不再作为文档偏差 |
| 页面内浮层 Esc 关闭 | 悬浮菜单、划词与确认已有；输入框 chip/写回失败面板未见 Esc 处理 | 只读记录，需内容模块负责人处理；字幕属于播放状态，不自行赋予 Esc 停止播放含义 |
| PDF 阅读与导出 | 阅读器有独立状态文案，导出/OCR 由 PDF 同事迭代 | 本轮只读截图，不改阅读器与 PDF 规格 |

界面未增加账号、遥测、开发者服务或默认开启的能力。没有调用真实翻译服务；浏览器 mock/触屏模拟不代表 Android 真机验收。
